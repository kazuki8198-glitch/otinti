# FLIGHT LAB 使い方

> **本アプリは公開情報を基にした非公式の自主学習用教材です。実機訓練、教官の指示、POH/AFM、SOP、航空法規を優先してください。**
>
> ANA の公式ソフトウェアではなく、認定された訓練装置（FTD など）でもありません。飛行時間・技能・資格（ソロ、ライセンス等）の証明にはなりません。実在の空港・空域・管制では使えません（NOT FOR NAVIGATION）。

この版（v2）は、空島フライトの飛行モデル・操作・画面の作りを移植し、すべての操作に「何が動くか・何のために使うか」の説明を付けました。教科書と課程も大きく増やしています。

---

## 1. 開き方

1. `FLIGHT-LAB.html` を **ダブルクリック**して Chrome で開きます（インストール、ローカルサーバー、npm、Python は不要）。
2. 最初に「はじめに」の注意が出ます。読んだら「理解しました」を押します。
3. スタートメニューが出ます。インターネットに接続していなくても、Google 3D 以外はすべて使えます。

**動作環境**
- Chrome（Windows / macOS）の最近の版。WebGL2 が必要です。
- 想定は Intel Iris Xe 程度のノート PC です。
- 画面が狭いときは F11（全画面）を押すか、飛行画面右上の「配置」で外部視界と計器の大きさを切り替えます。

## 2. スタートメニュー

左側に 9 つの入口、右側に操作の設定と自由飛行があります。

| 番号 | 入口 | 内容 |
|---|---|---|
| 01 | 課程表（スクール） | 飛行 33 課目 × 3 レベルと地上学科。公開されている訓練の順番に並んでいます |
| 02 | 教科書 | 全 23 章・102 節。飛行の原理から多発・CRM まで、出典付き |
| 03 | 学科テスト | 13 分野・130 問（4 択、毎問に解説） |
| 04 | 操作ガイド | すべてのキーとゲームパッド：何が動くか・何のために使うか。画面の見方と飛び方のコツ |
| 05 | G1000 型 PFD の読み方 | 計器を 1 つずつ説明するチュートリアルと、読み取り練習 |
| 06 | Sanford・英語交信 | 空港の資料（模式図）と ATC 復唱の 6 場面（音声） |
| 07 | 学習記録 | 課目の結果・講評・メモ（JSON の書き出し・読み込み） |
| 08 | Google 3D（任意） | Sanford 周辺の写実的な外部景観（自分の API キー・メモリのみ） |
| 09 | このアプリについて | 非公式教材であること、実装したもの・していないもの、データの扱い |

**操作の設定（右上）**

| 設定 | 意味 |
|---|---|
| 操作の感度（低・中・高） | キーとスティックでどれだけ大きく舵が動くか。最初は「低」 |
| ピッチ（W / S）：離すと姿勢を保つ / 離すと中立 | 「保つ」は空島フライトの標準。押している間だけ機首の角度が動き、離すとその角度を保ちます。「中立」は本物の操縦桿に近い動き |
| 自動ラダー（U） | ボールを自動で中央に保ちます。OFF にすると離陸・上昇で右ラダー（E）が必要になります（本物と同じ）。**片発停止の課目では使えません** |
| 操縦アシスト（自由飛行のみ） | キーを離すと翼を水平・水平飛行に戻す教材補助。訓練課目では使えません |
| サウンド | エンジン音・失速警報・管制の英語音声（ブラウザの音声合成） |

**自由飛行（右下）**：機体（Archer / Seminole）、開始位置（LAB RWY 36・ダウンウインド・最終進入 5 km・訓練空域 3,000 ft・ILS の開始点・Sanford 上空）、風（穏やか・向かい風 5 kt・横風 12 kt・突風を伴う横風 15 kt）を選んで、評価なしで飛べます。

## 3. 課程表（スクール）

- 左に段階と課目の一覧、右に選んだ課目の**ブリーフィング**が出ます。
- ブリーフィングには次が書いてあります。
  - **目的**：この課目で何ができるようになるか
  - **なぜ**：実際の飛行で何のために必要か
  - **手順**：教官が説明する順番
  - **使うキー**
  - **基準**：合格の許容幅（どの公開資料を参考にしたか）
  - 関連する**教科書の節**へのボタン
- 右上でレベル（導入・基礎・精度）を選び、「始める」を押します。

### レベル

| | 導入 | 基礎 | 精度 |
|---|---|---|---|
| 許容幅 | 基礎の 1.5 倍 | 基準のとおり（自家用 ACS を参考） | 基礎の 0.6 倍（事業用・計器飛行の水準に近い） |
| 連続保持の時間 | 半分 | 基準のとおり | 1.5 倍 |
| 目安（姿勢と出力）・ヒント | 表示 | 表示 | 出さない |

### 評価のしかた
- 手順ごとに目標（高度・速度・針路・バンク・昇降率・CDI など）があり、許容幅に入っているかを毎瞬見ています。
- **連続保持**：すべての目標が同時に許容幅に入っている時間を数えます。**1 つでも外れると 0 に戻ります**。決められた秒数を続けると次の手順へ進みます。
- 手順の合否：その手順の時間の **85% 以上が許容幅内**、かつ**最大のずれが許容幅の 1.6 倍以内**。
- 課目の評価：全項目合格で S / A / B（得点で決まる）、1 つでも不合格なら C。途中終了は「―」。
- 事故（脚が壊れる降下率・翼端の接地・湖への着水など）は終了。エンジン故障の課目で、安全な速度での滑走路外への接地は「不時着（乗員は無事という想定）」として扱います。

### 課目一覧（33 課目）

| 段階 | 課目 |
|---|---|
| 第 0 段階　地上学科 | G1000 型 PFD の読み方（チュートリアル）、PFD の読み取り練習、学科テスト 13 分野 |
| 第 1 段階　Archer の基礎（ソロまで） | 姿勢・出力・トリム ／ 直線水平飛行 ／ 上昇・降下・レベルオフ ／ 中程度の旋回（30°）／ 急旋回（45°）／ 低速飛行 ／ パワーオフ失速 ／ パワーオン失速 ／ 通常離陸と上昇 ／ 場周経路 ／ 通常着陸 ／ ゴーアラウンド ／ 離陸中止 ／ 離陸直後のエンジン故障 ／ 上空でのエンジン故障（滑走路へ滑空）／ ソロ前の審査（模擬 Check Flight） |
| 第 2 段階　航法・横風・目的地変更 | 横風着陸 ／ 短距離着陸 ／ 短距離離陸 ／ VOR の追跡 ／ 推測航法と目的地変更（見積もりを入力）／ 現在地を見失ったとき（GPS 故障） |
| 第 3 段階　計器飛行 | 基本計器飛行 ／ 異常姿勢からの回復 ／ 部分パネル（AHRS 故障）／ 待機経路 ／ ILS 進入 |
| 第 4 段階　Seminole（双発） | 双発の離陸と上昇 ／ 上空での片発停止（Identify・Verify・Feather）／ Vmc デモンストレーション ／ 離陸直後の片発停止 ／ 片発の進入と着陸 |
| 第 5 段階　CRM・TEM | TEM：脅威を予測して管理する（判断 → 管制との食い違いに気づく → 突風を伴う横風の着陸） |

課目の内容・許容幅は、FAA の公開資料（ACS・Airplane Flying Handbook・AIM）と公開されている訓練校のチェックリストを参考にした**教材の設計**です。ANA・訓練校のシラバスではありません。

## 4. 飛行画面

```
┌──────────────────────────────────────────────────────────────┐
│ 教官パネル（左上）                    操作の状態（右上）       │
│  手順 2 / 4：○○                        R / F スロットル  58%   │
│  教官の指示                            W / S 機首 保持 +3°     │
│  使うキー                              A / D 傾き −1°          │
│  目安（姿勢と出力）・直し方            Q / E ラダー 自動 R 3%   │
│  目標と現在値（✓ / ✗）                T トリム … V フラップ …  │
│  連続保持のバー・経過時間・ヒント      姿勢・ボール            │
│                   外部視界（LAB RWY 36・架空）                 │
│ [メニュー] [？操作(H)] [視点] [一時停止] [音] [配置]            │
├───────────────┬──────────┬───────────────────┤
│ PFD（G1000 型）│ オーディオ │ MFD（G1000 型）    │
└───────────────┴──────────┴───────────────────┘
```

- **教官パネル（左上）**：いまの手順の番号と名前、教官の指示、**使うキー**、**目安**（機体モデルから計算した「この姿勢とこの出力で、この速度・昇降率になる」）と直し方、目標値と現在値、連続保持のバー、ヒント。
- **操作の状態（右上）**：各キーがいま何をしているか（スロットル %・回転数、機首の保持角、傾き、ラダー、トリム、フラップ、ブレーキ、脚）。**いま使うキーは光ります**。
- **H キー**：いまの課目で使うキーと、その意味（何が動くか・何のため）を一覧表示。
- **チェックリスト**：課目によっては最初にチェックリストが出ます。Enter で 1 項目ずつ確認します。設定ができていない項目（例：フラップが UP でない）は先へ進めません。
- **管制（ATC）**：英語の指示（文字と音声）と 3 つの答えが出ます。1〜3 キーで正しい復唱を選びます。理由が表示されます。
- **見積もり**：目的地変更の課目では、新しい目的地への針路・距離・時間を入力します。
- **講評**：課目が終わると、手順ごとの合否・値・基準、次に意識すること、メモ欄（学習記録に保存）。
- **一時停止（P / Esc）**：再開・最初から・操作ガイド・教科書・課程表へ。自由飛行では「記録を保存」。

### G1000 型パネル
- 「**G1000型配置と基本概念を学ぶ教材**」です。Garmin 製品の再現ではありません。
- **PFD**：姿勢、速度テープ（白・緑・黄の帯と V 速度。Seminole は赤線 Vmc・青線 Vyse）、高度テープ、昇降計、HSI（HDG バグ、CDI、TO/FROM、マゼンタの菱形＝GPS の航跡）、グライドスロープ、DME、風、予備計器（STBY）。
  - CDI の目盛りは G1000 の HSI と同じ**片側 2 ドット**：VOR は 1 ドット 5°（2 ドットで 10°）、ローカライザーは 1 ドット約 1.25°、グライドスロープは 1 ドット約 0.35°、GPS は 2 ドットで 1.0 NM（TERM）。
  - AHRS の故障では姿勢・方位に、GPS の故障では GPS のコースに、赤い × やフラグが出ます。
- **オーディオパネル**：COM1/COM2 の MIC、受信ランプ、周波数（COM 25 kHz・NAV 50 kHz）と ⇄。**送信不可**（実際の管制にはつながりません）。
- **MFD**：エンジン欄（双発は左右 2 基）、地図（架空訓練点・飛行計画）、FPL。油圧・油温・EGT などモデルが計算していない値は **「—」（未実装）**。
- **自動操縦はありません**（HDG バグと ALT SEL は目印だけ）。

## 5. 操作

### キーボード（空島フライトと同じ配置）

| キー | 何が動くか | 何のために使うか |
|---|---|---|
| S / ↓ | 機首を上げる（操縦桿を引く） | 上昇・減速・フレア・ローテーション。押している間だけ機首の角度が動き、離すとその角度を保つ（設定で「離すと中立」） |
| W / ↑ | 機首を下げる（操縦桿を押す） | 降下・加速・失速からの回復（迎え角を減らす） |
| A / D（← / →） | 左右に傾ける（エルロン） | 旋回。目標のバンクで離す |
| Q / E | ラダー・前輪 | ボールを中央に。離陸・上昇は右（E）。地上でまっすぐ走る。片発では生きている側 |
| R / F（PageUp / PageDown） | スロットル 増 / 減 | 押し続けると速く動く。水平では速度、上昇・降下では昇降率を決める |
| Shift+R / Shift+F | スロットル 全開 / アイドル（一気に） | 離陸・ゴーアラウンド・失速の回復 / 離陸中止・接地前 |
| T / Shift+T | トリム / トリムを中立へ | いまの速度で手を離しても姿勢が続くように。操縦の力を消す |
| V / Shift+V | フラップを 1 段下げる / 上げる | 遅く・深い角度で降りる。白い帯（Vfe 以下）でだけ |
| G | 脚の上げ下げ（Seminole） | 上昇を確かめてから UP、着陸前に DOWN（緑 3 つ） |
| B / Space | ブレーキ（押している間） | 地上の減速・停止、離陸中止、短距離着陸 |
| [ / ] | 左 / 右のプロペラをフェザー（Seminole） | 止まったエンジンのプロペラの抗力を最小に。自由飛行では Shift で再始動 |
| Z / X | ラダートリム 左 / 右 | 片発で踏み続ける足を楽にする |
| U | 自動ラダーの ON / OFF | 教材の補助（片発の課目では使えない） |
| L | 水平に戻す（自由飛行のみ） | 教材の補助 |
| Enter | チェックリストを進める | |
| 1 / 2 / 3 | 管制への答えを選ぶ | |
| C | 視点：操縦席 / 後方 | 後方視点は機体の姿勢や舵の動きを見るため |
| H | いま使うキーの説明 | |
| P / Esc | 一時停止 | |

### ゲームパッド（標準配置。PS5 DualSense / Xbox）

| 入力 | 操作 |
|---|---|
| 左スティック | 傾き（左右）と機首（上下。手前で機首上げ） |
| 右スティック左右・L1 / R1 | ラダー |
| 右スティック上下・十字キー上下 | トリム |
| R2 / L2 | スロットル 増 / 減 |
| × / A | ブレーキ（チェックリスト表示中は「次へ」） |
| ○ / B | フラップ下げ（管制の場面では答え 2） |
| □ / X | フラップ上げ（管制の場面では答え 1） |
| △ / Y | 視点（管制の場面では答え 3） |
| Share / Back | 脚 |
| Options / Start | 一時停止 |
| 十字キー左右 | 左 / 右のフェザー |
| L3 / R3 | 水平に戻す（自由飛行）/ 自動ラダー |

## 7. 学習記録

- 課目が終わると自動で保存されます。自由飛行は一時停止メニューの「自由飛行の記録を保存」で保存します。
- 保存先はこのブラウザの localStorage だけです。サーバーには送りません。
- **保存するもの**：課目・日時・レベル・機体・結果・評価・手順ごとの合否と値・高度と速度の履歴・接地などの出来事・メモ・練習時間（シミュレータ上の時間）。
- **保存しないもの**：API キー、Google のトークンや地形データ、個人情報。メモにキーやトークンらしき文字列を貼った場合は自動で削除します。
- **本記録は教材シミュレータの練習記録です。正式な飛行日誌（logbook）ではなく、飛行時間として扱えません。**
- 「JSON に書き出す」「JSON から読み込む」で別の端末と統合できます（読み込み時は知らない項目を捨て、型を検査します）。

## 8. Google 3D（任意）

Sanford 周辺（表示原点 約 28.777, −81.238 を中心に半径約 12 km）の外部景観を、Google の公式 **Map Tiles API（Photorealistic 3D Tiles）** で表示できます。

1. Google Cloud で Map Tiles API を有効にし、API キーを作ります（請求先アカウントが必要）。キーには **API の制限（Map Tiles API のみ）** と**割り当て（クォータ）の上限**を設定してください。
2. メニューの「Google 3D（任意）」でキーを入力して「接続」。
3. 「Sanford 上空へ（自由飛行）」で Sanford の上空に移動します。

- **キーはメモリだけ**に保持します。localStorage・記録・JSON・URL には保存しません。再読み込みや「切断（キーも消去）」で消えます。キーは tile.googleapis.com へのリクエストにだけ付けます。
- 使うのは Google の公式 Map Tiles API だけです。Street View 画像の取得・スクレイピング・保存、非公式 API の利用はしません。タイルの保存・事前取得もしません。
- 表示中は画面左下に **Google Maps** の表記と、データ提供元（著作権表示）を出します。
- Google のデータは外部景観の表示だけに使います（衝突判定・実在空港への接地・滑走路・空域・管制には使いません）。
- 接続のたびに Google Maps Platform の課金対象になります。料金・無料枠は Google の最新の案内で確認してください。
- `file://` で開くとブラウザは Referer を送らないため、キーの「ウェブサイトの制限」は使えません。API の制限とクォータの上限で守ってください。

## 9. 困ったとき

| 症状 | 対処 |
|---|---|
| 外部視界が出ない | WebGL2 が無効の可能性。Chrome の設定でハードウェア アクセラレーションを有効に |
| 機首が左に振られる | プロペラの左偏向（本物と同じ）。右ラダー（E）か、自動ラダー（U）を ON に |
| 高度が保てない | まず翼を水平（A / D）、次に機首（W / S）で 1〜2° ずつ、落ち着いたらトリム（T） |
| 片発で真っすぐ飛べない | 生きているエンジン側のラダー（E / Q）を踏み、生きている側へ 2〜5° 傾け、Z / X でラダートリム |
| 先へ進めない | 教官パネルの目標（✗ の項目）と H キーの説明を確認。チェックリストは設定してから Enter |
| 音が出ない | 右上の「音」を ON に。英語 ATC は OS に英語の音声が必要 |
| 記録が残らない | プライベートモードなどで localStorage が使えない。JSON の書き出しは使えます |

flight-lab/
