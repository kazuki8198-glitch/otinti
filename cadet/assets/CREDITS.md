# 素材とライセンス

## テクスチャ（`assets/tex/`）

すべて ambientCG（https://ambientcg.com）の素材で、ライセンスは CC0 1.0 です。このリポジトリの別ブランチ（`claude/what-is-this-db5aue` の `models/tex/`）に、縮小済みの版がすでにありました。ここでは WebP に変換し、粗さのマップは 512 px に縮めています。

## 人物の模型（`assets/model/actor.glb`・`actor-near.glb`）

自作です（素材は使っていません）。`tools/actor/build_actor.py` を Blender 5.2 でコマンドから動かして作ります（`blender -b --factory-startup -P tools/actor/build_actor.py -- 寸法.json assets/model/actor.glb - far`、近くの人の模型は `actor-near.glb - near`。寸法は `node tools/actor/anchors.mjs` が `src/npc/actor.js` から書き出します）。

- 顔・髪（短髪・刈り上げ・後ろで結んだ長い髪・まとめ髪）・耳・眉・目・まぶた・瞳・口と、制服（シャツ・襟・ネクタイ・胸ポケット・肩章と線・翼の記章・名札・ネックストラップと ID カード）。
- 形はスクリプトの中の関数で細かく作り、Blender の間引き（デシメーション）で三角形の数を減らし、細かい形の法線を写します。陰（アンビエントオクルージョン）と唇やまぶたの色は、頂点の色に焼き込みます。
- 名札の文字は、ゲームが起動時に 5×7 の点の字で書きます（`src/npc/actor.js`）。
- 翼の記章は架空の翔洋航空のもので、実在の会社の記章をまねていません。

## Archer の外観の模型（`assets/model/archer.glb`・`archer-far.glb`）

自作です（素材もフォントも使っていません）。`tools/aircraft/build_archer.py` を Blender 5.2 でコマンドから動かして作ります（`node tools/aircraft/spec.mjs > 寸法.json`、`blender -b --factory-startup -P tools/aircraft/build_archer.py -- 寸法.json assets/model/archer.glb - near`、遠くの機体の模型は `archer-far.glb - far`）。

- 寸法は FLIGHT LAB の物理の記述（胴体の輪・翼・尾翼・脚・エンジン）から取り、動翼は `acmesh.js` のヒンジの線の上で動きます。客室の形は操縦席（`src/aircraft/cockpit.js`）の窓・風防・天井に合わせています。
- 胴体・カウリング・空気取り入れ口・スピナーとプロペラ・テーパーした翼と翼端・フラップとエルロン・スタビレーター・垂直尾翼とドーサルフィン・ラダー・脚の緩衝支柱と車輪とホイールフェアリング・風防と窓・ドアやカウリングの合わせ目・燃料キャップ・ピトー管・失速警報・アンテナ・ステップ・係留リング。
- 塗装は架空の翔洋航空のもの（白に濃い青の帯と金の線、垂直尾翼の上が濃い青）で、実在の会社の塗装をまねていません。登録記号（架空の N7xxSY）の文字は、スクリプトの中で線で書いた字です。
- 陰（アンビエントオクルージョン）は頂点の色のアルファに焼き込みます。

## Seminole の外観の模型（`assets/model/seminole.glb`・`seminole-far.glb`）

自作です（素材もフォントも使っていません）。`tools/aircraft/build_seminole.py` を Blender 5.2 でコマンドから動かして作ります（`node tools/aircraft/spec.mjs pa44 > 寸法.json`、`blender -b --factory-startup -P tools/aircraft/build_seminole.py -- 寸法.json assets/model/seminole.glb - near`、遠くの機体の模型は `seminole-far.glb - far`）。

- 寸法は FLIGHT LAB の PA-44 の物理の記述（翼・T 字尾翼・翼のエンジン・引き込み脚）から取り、動翼・脚・2 つのプロペラは `acmesh.js` のヒンジと軸で動きます。客室は Archer の模型と同じ形を、Seminole の目の位置へ動かしたものです（操縦席が同じため）。
- とがった機首（荷物室）、長い尾部、T 字尾翼とその付け根の覆い、左右のナセル（カウリング・空気取り入れ口・合わせ目・排気管）、反対向きに回る 2 つのプロペラとスピナー、引き込み脚（緩衝支柱・トルクリンク・脚の扉・前脚のフォーク）、風防と窓、ドアと荷物室の合わせ目、アンテナ、ステップ。
- 塗装は Archer と同じ架空の翔洋航空のもの。登録記号（架空の N452SY・N455SY・N457SY）の文字は、スクリプトの中で線で書いた字です。
- 陰（アンビエントオクルージョン）は頂点の色のアルファに焼き込みます。

## 操縦席の模型（`assets/model/cockpit.glb`）

自作です（素材は使っていません）。`tools/aircraft/build_cockpit.py` を Blender 5.2 でコマンドから動かして作ります（`node tools/aircraft/cockpit-spec.mjs > 寸法.json`、`blender -b --factory-startup -P tools/aircraft/build_cockpit.py -- 寸法.json assets/model/cockpit.glb [見本の絵のフォルダ|-]`）。座席・グレアシールド・操縦輪は、部品ごとのファイル（`tools/aircraft/cockpit_seats.py`・`cockpit_glareshield.py`・`cockpit_yokes.py`）にあり、同じコマンドで一緒に作られます。作る前と後の絵は `docs/cockpit/` にあります（`band-*.jpg`、`parts-*.jpg`）。

- 操縦席（`src/aircraft/cockpit.js`）のうち、次の部分を模型にしています。ほかの部分（計器盤・壁・ドア・床・ペダルなど）は、今までどおりプログラムで作っています。
  - 天井まわり：天井の内張り（縫い目と、骨の間の布のたるみ）、天井の両端の縁の飾り、風防の上の枠、A ピラーの内張り、風防との間のゴム、サンバイザー（蝶番の棒と 2 つの留め金）。
  - 前の 2 席と後ろの席：革の座席（縫い目で区切った中央、パイピングのある盛り上がり、ヘッドレストと柱、枠とレール、リクライニングのレバー）。
  - グレアシールド：縫い目のある丸いパッドと、風防の下の縁のゴム。
  - 2 本の操縦輪：G1000 NXi の Archer の M600 型（台形の台と、少し明るい板、太い握り、外側の握りの上のスイッチの箱）。動く部品として、操縦に合わせて動きます。板の上の Piper のシェブロン（2 つの三角）は、形だけを浮き出させたもので、文字は入れていません。形は Piper の写真（Archer TX・LX・Seminole NXi）を見て作りました。
- 寸法は `cockpit.js` の客室の配置（目の位置・窓の帯・天井の弧・風防・計器盤・座席の位置・操縦輪の軸）を `cockpit-spec.mjs` が書き出したものから取り、模型が残りの部分とぴったり合うようにしています。
- 色は `cockpit.js` の表面の表の色で、ざらつき・金属らしさ・表面の細かい模様（革のしぼなど）も、部品の名前（`headliner.roof`・`seats.seat` など）で同じ表から取ります。近くの物の陰（5 cm のレイ）を頂点の色のアルファに焼き込み、ゲームが窓から見える空の量の陰を掛けます。
- 模型がページにないとき（または模型にない部分）は、前のプログラムの形（簡単な板・管・箱）で描きます。

## 737 型の外観の模型（`assets/model/jet737.glb`・終章）

自作です（素材もフォントも使っていません）。`tools/aircraft/build_737.py` を Blender 5.2 でコマンドから動かして作ります（`blender -b --factory-startup -P tools/aircraft/build_737.py -- assets/model/jet737.glb [見本の絵のフォルダ|-]`）。作る前と後の絵は `docs/737/` にあります（`model-*.jpg` が模型、`01-apron-before.jpg` が並べる前の駐機場、`02-apron-after.jpg` が並べた後、`03`〜`05` が右席からの眺め）。

- 「よくある双発の細胴ジェット旅客機」の形を、大まかな寸法（全長およそ 39 m・翼幅およそ 36 m）で一から作ったものです。特定の会社の図面や 3D データは使っていません。遠くから見るための模型で、約 1 万の三角形を 1 つの形にまとめています（動く部分はありません）。
- 胴体（機首・風防・客室の窓・ドアの合わせ目）、後退翼と上に曲がった翼端、翼の下の 2 つのエンジン（空気取り入れ口・排気口）、水平尾翼、垂直尾翼、脚。
- 塗装は架空の翔洋航空のもの（白に濃い青の下半分と金の線、垂直尾翼に金の太陽と白い波）で、実在の会社の塗装やロゴをまねていません。「SHOYO AIRWAYS」の文字は、スクリプトの中で線で書いた字です。
- 陰（アンビエントオクルージョン）は頂点の色のアルファに焼き込みます。

## 音（ファイルなし）

すべてブラウザの Web Audio でその場で作っています（`src/audio/sfx.js`）。録音した音や音の素材は使っていません。

- エンジン：Lycoming O-360 の 4 気筒（1 回転に 2 回の爆発）を、気筒ごとに少しずつ違う圧力の波で作り、排気・プロペラの羽根の音・風切り音と合わせています。Seminole は左右のエンジンをそれぞれの回転数で鳴らし、少し左右に分けています（回転がそろわないと、うなりが聞こえます）。
- スターター・始動・接地・失速警報・脚のポンプ・操縦席のスイッチ。
- 周りの音：風、鳥、遠くを飛ぶ小型機、建物の空調、足音（床の材料ごと）、扉。
- 無線：スケルチの開閉と、受信中の雑音（300〜3,000 Hz）。管制官と教官の声は、ブラウザの音声合成（設定で ON のとき）。

## 外のサービス（設定で ON にしたときだけ）

どれも初めは OFF で、OFF のあいだはどこにも通信しません。

- Anthropic の Claude API（AI 教官）：設定で ON にして、プレイヤーが自分の API キーを入れたときだけ、質問、直前のやり取り（3 往復まで）、今日の場所（ブリーフィング室か講評）・訓練の段階・日付・課目・天気（METAR）、その日の結果（講評のとき：外部点検・無線・タキシーの停止線・機体の損傷・ランナップの判断・課目の評価・TEM）、教科書の目次と各節の要約・質問に近い節、教官の話し方の決まりを Anthropic へ送ります。キーはこのブラウザの中だけ（初めはページを閉じるまでのメモリ、「このブラウザに覚えておく」を選んだときだけ localStorage の `cadet.secret.anthropic`）に置き、リポジトリやビルドしたファイルには入りません。料金と使い方は、キーを持つ人と Anthropic との契約（利用規約・使用ポリシー）によります。
- ブラウザの音声認識（マイクで交信）：Web Speech API を使います。多くのブラウザ（Chrome など）は、声を認識のためにブラウザの会社のサーバーへ送ります。
- Google の 3D の地図（Sanford の周り）は、作っていません（理由は `PLAN.md` の M8 に書いています）。
