## 1. この角度の主張と、証拠を見て直したところ

### 1.1 主張：なぜ「進化」で足りるのか

1. **2 冊とも、事実はほぼ正しい。** 12 の主題すべてで「大きな事実の誤りはない」と報告されています。教科書は約 60 か所の規則の引用（law-atc-radio）、約 80 項目の操縦の数値（vfr-flying）、POH・AFH・AIM の数値がすべて一致しました。基礎教材も計算はすべて検算で一致しました。直す対象は「本の作り替え」ではなく、**台帳にできる有限の誤り**（教科書 約 80 件、基礎教材 約 46 件）です。
2. **2 冊の強みは「高さ」が違うので、同じ場所で戦っていない。** どの主題でも「手順・数字・図・シミュレータは教科書、原理・定義・判断・記述問題は基礎教材」と分かれました（aero・systems・instruments・weather・navigation・ifr・multi・vfr-flying）。重なる主題でも内容は補い合うので、**片方を消すと必ず何かを失います**。結ぶのがいちばん得です。
3. **教科書は 4 つの製品の土台。** 節 ID、`bk.aim`、`bk.key`、最初の `<svg>` に、課目・学科テスト・英語交信・TEXTBOOK・CADET がつながっています（integration）。章 ID と節 ID の頭は一致しないので、作り替えは機械的にできません。**形を変えないこと自体が、品質を守る手段**です。
4. **基礎教材は Word 原稿の生成物で、生成スクリプトはリポジトリにない。** README の決まり 3 は「文言を変えない。直すなら Word を直して作り直す」です。中身を書き換えると由来が切れ、`preview.html` との比較テストも壊れます。**原本を保ち、訂正を分けて見せる**のが、由来を守るいちばん確かな方法です。
5. **読む人の道は 1 本で足りる。** 訓練生が毎日読むのは課程の順の教科書です。基礎教材は「なぜ？」と思ったとき、JCAB の学科の前、記述で説明する練習のときに開く本です。2 冊の並びを合わせる必要はなく、**地図とリンク**があれば行き来できます。

## 3. 設計の決まり（10 条）

1. **章 ID・節 ID・章の並び（27 章）・章番号は変えない。** 新しい中身は新しい ID。第 7 部の章は一番後ろ（今の第 27 章 `sim` の後）に置くので、既存の「第 N 章」はすべて同じ番号のまま。
2. **節の形を守る**：ねらい（`bk.aim`）→ 最初の図 → 説明 → ここが大切（`bk.key` 2〜4 項目）→ 注意 → 考えてみよう → 写真は最初の図より後 → `bk.sim` は最後。既存の節で `bk.key` を変えるのは誤りを直すときだけ。CADET のテストが文字で決めている所（`ops.trim` の最後の要点、`aero.forces` の要点 2 つ、`aero.lift` の「この教材の Archer」、`ifr.np` の「自動操縦（オートパイロット）があることが多いです。」、`me.basics` の書き出し、`nav.divert` の「まず向きを変え」など）は残す。
3. **章末の確認問題と学科テストは「後ろに足すだけ」**。並べ替え・削除はしない（記録 `bookQuiz` のキーが「章ID.番号」のため）。誤りは問題の中で直す。
4. **「日本では」の囲みは新しい部品 `bk.jp()`**（`<div class="bk-jp">`）。`FL.book` の API に足すだけで、既存の書き方は変えない。中身は「違い・条番号・e-Gov の確認日・第 7 部へのリンク `{ch:jlaw}`」。CADET は既定でこの囲みを消す（1 行の変更。所有者が決める）。
5. **基礎教材へのリンクは教科書の本文（`FL.book.html`）に入れない。** 相互リンクの表（`FL.bookLinks`）を FLIGHT LAB の画面が節の終わりに描く。TEXTBOOK と CADET は基礎教材を持たないので、表を読まない（壊れるリンクが生まれない）。
6. **基礎教材のデータ（`kiso-data.js`・`data/`・`fig/`・`photo/`）は一字も変えない。** テストで sha256 を固定する。訂正は `kiso/kiso-errata.js`（手で書く小さなファイル）に持ち、画面で本文と分けて「訂正・補足（FLIGHT LAB 編集）」の枠に出す。
7. **規則の数字には国を付ける。** 教科書の本文で、どこの規則か書かずに規則の数字を置かない。取り違え表（8.2）の 31 項目は、教科書の該当節に「日本では」の囲みがあることをテストで確かめる。
8. **図は暗い板（#0b1422）・幅 360〜440・文字 12 以上・単独で正しい XML・`aria-label`。** 基礎教材の図を教科書で使うときは描き直す（元の図番号を記録）。基礎教材のページでは元の白い図をそのまま使い、拡大表示を足す。
9. **写真のクレジットは写真の下に必ず。** CC BY-SA の写真は新しく切り抜き・色調整・文字入れをしない（基礎教材の決まり 2 を新しい写真にも当てる）。教科書の既存の写真は「縮小などの加工あり」の表示のまま。航空会社の写真は教科書に入れない。
10. **事実は出典つき。** 数値は「教材値」「参考値（出典）」「条文（e-Gov、確認日）」のどれか。一次資料で確かめられない日本の項目（AIP Japan の一部など）は「推測・要確認」（`bk.est`）にするか、書かない。新しい節は書いた人と別のエージェントが一次資料で確かめる。
