# 仮想資金 投資シミュレーション（東証プライム）

実資金は使わず、発注機能はありません。価格は Yahoo Finance のスナップショット（東証は通常15〜20分遅延）です。

- `engine.js` 売買エンジン（指標・採点・サイズ・出口・コスト・説明文・バックテスト）
- `run.js` 取得・スキャン・記録・サイト生成（GitHub Actions で実行）
- `index.html` 画面（静的 JSON を読む）
- `.github/workflows/sim.yml` 取引時間中に22回/日のスキャン、平日21:00の温め直し、日曜のバックテスト

データはブランチ `sim-data`（履歴キャッシュ・状態・売買記録）、公開サイトは GitHub Pages（予備: ブランチ `sim-site`）。
