# FLIGHT LAB

公開情報を基にした**非公式の自主学習用**飛行訓練教材です。ブラウザで 1 ファイルを開くだけで動きます。

> 本アプリは公開情報を基にした非公式の自主学習用教材です。実機訓練、教官の指示、POH/AFM、SOP、航空法規を優先してください。
> ANA の公式ソフトウェアではなく、認定訓練装置でもありません。NOT FOR NAVIGATION。
