## 目標と到達点

目標: アイドル・パワーオフ失速からプロスピン操作で発達したスピンが入り
（ヨーレート ≥ 1回転/4秒＝90°/s を持続、αが深失速域を維持）、標準手順 P.A.R.E. で
回復でき、回復までの高度損失が plausible な範囲に収まること。

到達点（最良変種 physics-best-variant.js、本フォルダ収録・未統合）:
- 失速ブレークとインシピエントスピンは再現できた（進入トレース probe23）:
  ブレーク t≈3.6s → α 23→35°、機体ヨーレート −65°/s、バンク 85° まで発達（約1旋回）。
- しかしスティープスピン（α 30〜50°）はその後コーニング崩壊で離脱する
  （後述）。持続するのはフラットスピン側のモードのみで、目標の形ではない。

## 根拠計測値

### ベースライン（現行 physics、監査記述の再確認）
- スラム進入（アイドル）: αピーク 18.6° → 4.2° に崩落、以降 α≈13°・IAS 90〜115 kt・
  ヨーレート約 15°/s・沈下 5,000〜10,000 fpm のスパイラルダイブ。stallW ≈ 0。
- 進入→スピン→PARE の自動採点（grid.mjs、進入後13秒スピン保持→PARE）:
  `fracAlphaInRange 0 / meanAlpha 12.8 / meanYawRate 32°/s / meanIas 78 kt /
  meanSink 5,304 fpm`（スピンサンプル域で α が 22〜48° に入る割合 0%）。

### 凍結計測で特定した欠陥（いずれも実在のモデル欠陥）
1. **尾翼失速の崖**: 水平尾翼の要素揚力勾配 at が 11.2/rad と急で、線形外挿 CL が
   3.6〜4.0 に達してから失速ブレンドで 1.6 へ落ちるため、機体α 20〜22° で
   ピッチ加速度が 0 → **−139°/s²**（α20 で −67、α22 で −139、ベースラインでは
   α20 で −193°/s²）へ跳ねる（probe25: 要素ピッチモーメント aeM0 が
   α16 の +162 Nm → α22 の −4,484 Nm）。これが進入時の α 崩落の主因。
2. **主翼失速後 CL の崖**: 線形 CL（α20° で 2.1）と平板曲線 1.15·sin2a の
   ブレンドにより α 17→19° で CL 勾配 ≈ −14.6/rad（実翼型は −0.5〜−1.5/rad 程度）
   → 進入時のスナップロール（ロール発散）の主因。
3. **ピッチ反減衰**: スピンスライス（α32、Ω −100°/s）で d(pitchAcc)/d(w0) ≈
   **+18°/s²/(rad/s)**（probe26）。巡航チューニング残差 dCmq = +4.65 が尾翼失速後も
   残り、要素側の減衰（≈ −15）を上回る。コーニング振動の励振源。
4. **ロール反減衰の残差**: dClp 残差 +0.273（巡航では要素の過減衰を相殺する正値）が
   深失速でも残り、ヨー勾配ロール（Clr、スピンスライスで約 +2,700 Nm）と合わさって
   ロールスルーを起こす。
5. **慣性カップリング**: スピンスライスでレート 0 では pitchAcc ≈ 0（静的釣り合い
   成立）だが、回転を入れると pitchAcc **+74°/s²**（Ω −100）。内訳は慣性項
   w1·w2·(I_yaw − I_roll)/I_pitch ≈ +69°/s² で、実機ではロータリーバランスが
   相殺する分がモデルに無い。
6. **胴体側力の不足**: 深失速・大バンクでは重力の体軸横成分（≈0.5W）の釣り合いに
   必要な CY が、フィン失速後のモデルには無い（残差 dCY −0.161/rad のみ）。

### 最良変種（physics-best-variant.js）の内容と計測
上記への対処として以下を実装した変種（いずれも stallW ゲート付きで通常域は不変）:
- 失速後 CL 曲線に実翼型相当のバンプ追加（CLmax ≈1.55、勾配 −0.03〜−0.09/°）
- 要素 lin の物理的飽和（主翼 ±1.8 / 尾翼・フィン ±1.55）
- 失速後 CD に平板相当の sin⁴ 項（CD90° ≈ 2.2）
- ロータリーピッチ交差項 Cm_pr 型（KC 4.5、stallW ゲート 0.45〜0.8）
- 失速後ロール減衰 ClpPost −0.16（深失速ゲート）
- 巡航残差 dClp / dClr / dCnr / dCmq の深失速ゲートアウト（(1 − deepK) 倍）
- ロータリーヨー項（Cn_rot 線形、α バンド 20〜70° 限定、係数 0.06·r̂）
- 深失速時の胴体側力 −0.45·β（同ゲート）

結果:
- 凍結ピッチ掃引（probe8/probe25）: スパイク解消。Mp は α16 +299 → α19 +116 →
  α20 −101 → α22 −457 → α24 −1,006 Nm（漸進的な失速ブレーク）。
- 凍結ピッチ減衰（probe26）: d(pitchAcc)/d(w0) が +18 → **−19°/s²/(rad/s)**（減衰化）。
- 凍結スピンスライス（probe13、α32/バンク25/Ω−100）: pitchAcc +74 → **+7.7**、
  rollAcc +101 → **−3.5**、yawAcc +0.8 → +19.6（自転側）。
- 進入（probe23）: 教科書的なインシピエント発達（α 35〜45°、約1旋回）。
- 直接初期化スピン（probe12）: **フラットスピンが持続** — α 81〜91°、ピッチ −1〜−9°、
  機首方位レート 約 95〜120°/s（8〜16s の8秒間で方位 1,009°→1,829°）、
  沈下 約 4,500 fpm、IAS 約 40 kt、g ≈ 1.0。ただし α が深すぎ（実フラットスピンでも
  60〜80° 程度）、スティープスピンではない。
- 進入からの自動採点（grid.mjs）: `fracAlphaInRange 0.13 / meanAlpha 79.8 /
  meanYawRate 68°/s / meanSink 4,263 fpm / PARE 回復は制限時間内に完了せず
  （recAltLoss null）`。進入はフリック状の離脱を経てフラットモードに入り、
  PARE ボットでは回復が完了しなかった。

### 不成立の核心（コーニング崩壊）
スティープ相（α 35〜45°、バンク 75〜90°）で、回転ベクトル w が世界鉛直方向の
コーニング（w ≈ Ω·up_body）から外れ、最大慣性軸（機体ヨー軸）方向へ移行する。
凍結計測では各スライスのトルク釣り合いはほぼ取れている（probe28: 発達相の
凍結加速度は pitch −1 / yaw +32 / roll +7）が、姿勢遷移に必要な w0 の変化
（ピッチ通過に伴い ≈ −24°/s² 級）を空力が供給できず、ピッチが −50° を越えて
垂直フリック → フラット/逆フラットモードへ落ちる。実機ではロータリーバランス
（回転流中の尾翼・胴体のモーメント分布）がこの軸移行を抑えるが、要素法＋残差
微係数の本モデルにはその分布情報が無く、単一係数の交差項では
スライス釣り合いと遷移動力学を同時に満たせなかった。

## 試した機構と棄却理由（時系列の要約）
1. 尾翼/フィン失速後「入射角シフト」（舵面による局所αシフト）: 初期は不発。
   最終盤に再試行すると尾翼揚力が増えてブレークで α が抜け悪化 → 棄却。
2. 尾翼ブランケティング（主翼失速率で尾翼効率減衰）: α20 のスパイクは改善するが、
   深失速の静的釣り合い（失速尾翼の揚力＝機首下げ）を壊し非物理タンブル → 棄却。
3. 主翼失速後 CL ディップ: ロール反減衰帯を広げスナップ悪化 → 棄却。
4. 失速ブレンド幅拡大（0.07→0.14 rad）: 効果なし → 棄却。
5. 空力中心（AC）後退（失速要素の作用点を 0.30c 後方）: 凍結では強力
   （pitchAcc +74→+7.5）が、ゼロレート深失速で機首下げ過大（−70〜−88）→
   スピンの α が抜ける。0.12c でも進入 α が崩落 → 棄却。
6. ロータリーピッチ交差項（上記・採用）: KC 7〜9 では進入の w1·w2 符号域で
   機首下げ過大となり α 崩落 → KC 4.5 に確定。
7. ロータリーヨー項 r̂|r̂| 二次型（KS 0.22）: フラットモードで正帰還暴走
   （方位レート 140°/s 超・数値発散例あり）→ 線形型 0.06·r̂＋αバンド限定に変更。
8. ロール減衰 ClpPost −0.35〜−0.40: バンク保持は改善するがピッチスライスは
   止まらず、−0.16 がスライス釣り合いと両立する上限だった。
9. Cmq ゲート＋CD sin⁴＋CL バンプ＋lin 飽和＋残差ゲート＋胴体側力: 上記の通り
   いずれも欠陥の実測に基づく改善として最良変種に採用したが、コーニング崩壊は
   解消しなかった。

## 次にやるなら（示唆）
- 回転流中の尾翼モーメントを直接モデル化する（ロータリーバランス表の導入:
  Cm/Cn を (α, Ω_nd) の2変数表にする）。本モデルの残差微係数の枠組みでは
  表への置換が可能な箇所（Mp / Nr の残差項）がある。
- 胴体の法線力・側力の分布（Munk モーメント）を要素として追加する。
  現在の要素法は胴体空力をほぼ持たない（側力は残差のみ、法線力なし）。
- スピン中のフィン局所流（回転による横流れ −5〜−16 m/s）が支配的なので、
  フィン要素の分割を増やし、回転流での失速/回復を検証する。
