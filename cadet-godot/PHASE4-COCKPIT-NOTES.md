## 1. 寸法根拠

### キャビン形状 — 移植元 `cadet/src/aircraft/cockpit.js`（898fe8a, next/integrated）

| 定数 | 値 | 意味 |
|---|---|---|
| EYE0 | (-0.30, 0.62, -0.40) | 左席の目（main.gd のカメラと一致） |
| FLOOR / FIRE / AFT | -0.40 / -1.45 / 1.65 | 床 / 防火壁 / 後部隔壁 |
| PZ / PTOP / PBOT | -1.10 / 0.465 / 0.03 | パネル面 / 上端 / 下端 |
| SILL / WTOP | 0.38 / 0.75 | 側窓帯の下端 / 上端 |
| HW / HWT / ROOF | 0.56 / 0.49 / 0.845 | 窓帯下端・上端の半幅 / ルーフ頂点 |
| WS | z0=-1.30, y0=0.425, z1=-0.84, y1=0.815, bow=0.12 | フロントガラス基部・上端・側方への反り |

派生式も原典どおり転記した: `bandX(y) = HW + KX*(y-SILL)`（KX ≈ -0.18919、
窓帯は上ほど内側へ傾斜）、`lowX(y)`（床付近で 0.46 まで絞る下壁プロファイル）、
`roofY(x) = WTOP + (ROOF-WTOP)*sqrt(1-(x/HWT)^2)`、`wsZ(x,y)`（bow 項で
フロントガラス両端が後方へ反る）。側窓ポリゴン W1/W2/W3 の (z,y) 頂点列も
原典の定義そのまま（W1: 前窓、W2: 後窓、W3: 最後部窓）。

### グレアシールドのアーチ — commit a79cba2 と `cadet/tools/aircraft/cockpit_glareshield.py`

898fe8a の cockpit.js 本体には弓なり仕様がまだ入っていない（リップは全幅フラット）。
アーチ寸法の出所は、同梱の glareshield 作業の記録である commit a79cba2
「bow the glareshield and the panel's top edge like the real aircraft」
（glare-base / growth/gfx の基点）と、その Blender 生成スクリプト
`cockpit_glareshield.py` の BOW 仕様・check() である:

- `GLARE.bow = [0.25, 0.545, 0.028, 4]`: 中央 |x| ≤ 0.25 はフラット、
  そこから四次曲線で落ち、ロールの端 |x| = 0.545 で **28mm ドロップ**。
  実機（Piper Archer TX のパネル写真、POH VB-2749 Fig 7-9）が根拠と記録されている。
  ドロップ量は「両端の下に見え続けなければならないもの」（画面・照準点・
  パネル上部の印刷、最狭は Seminole の速度プラカードで約 12mm の余裕）から
  決められた値で、中央クレストの目からの伏角 12.25° は不変。
- パネル上端も同じ弓なりに追随: `panelTopY(x) = PTOP - 0.008 - glareDrop(x)`。
- パネル面の角ラップ: `panelWrapZ(x)`: |x| ≤ 0.535 は 0、角 |x| = 0.553 で
  **最大 12mm 後方**へ二次曲線でスイープ（G5 等の左端計器は平坦部に載る）。
- A ピラー足元のチーク（壁色）profile は同コミットの (z,y) 形状を転記し、
  下端を `panelTopY(x) - 0.004` に合わせた。WS.y0 自体は直線のまま
  （外形・FLIGHT LAB と共有のため動かさない、という同コミットの判断に従う）。
- リップ profile ([z,y] 6 点) は 898fe8a の GLARE.lip 相当
  （(-1.096,0.451) … (-1.05,0.4795)）に各 x の drop を引いて掃引し、
  その先は原典フォールバック sheet と同じく slope 補間でフロントガラス
  基部 (wsZ(x, WS.y0)-0.002, 0.423) へ落とす。

## 2. 変更点

### src/cockpit_build.gd（Phase 2 の箱シェル → 原典形状のシェル）

- **側壁**: 下壁は `lowX(y)` プロファイルの面（床→シル）。窓帯は格子面
  （z 方向 100 分割 × y 20 分割）で、セル中心が窓ポリゴン W1/W2/W3 の内側に
  入るセルを欠き、実開口を作った。柱（W1–W2 間など）・上下帯は格子が残る。
  各窓には縁取り（リビール帯、帯平面から内側 2mm）と窓ガラス
  （半透明、影なし）を付けた。
- **フロントガラス**: `wsZ(x,y)` のガラス面（2 分割でなく 12×6 格子）、
  A ピラー トリム（側縁に沿う径 28mm のセグメント円柱 ×8）、上弓
  （トップボウ ×12 セグメント）、中央柱（径 11mm）を追加。
- **ルーフ**: 箱 → `roofY` アーチ面（フロントガラス上端から後部隔壁まで）。
  後部隔壁もアーチに沿う面に変更。防火壁の上端は原典どおり WS.y0-0.03 に下げた。
- **グレアシールド**: Box → 36×16 分割の掃引面。リップ profile × アーチ drop で
  中央フラット・両端 28mm ドロップを再現（テストで実測 28.0mm）。
- **パネル**: 箱 → フェイス面（上端が panelTopY、z に panelWrapZ）＋背面＋
  上端リボンで厚みを構成。計器が載る |x| ≤ 0.535 は平坦なのでベゼル・
  スロット・予備計器・オーディオの位置は Phase 2 から 1mm も動いていない。
- **チーク**: 左右 A ピラー足元に壁色の詰め物を追加（弓なりで下がった
  グレア端とフロントガラス基部の隙間を埋める原典の部品）。
- **ドア（右）**: シーム 3 本（暗線）、ハンドル、ラッチ、ポケットを追加。
  左右に内張りパネル、シルトリム、アームレスト前後、B ピラー トリム、
  ルーフ際トリムも追加。
- 既存の計器パネル付属品（ベゼル/スロット、操縦桿、座席、ペダル、コンソール、
  スロットルレバー類）は寸法・名前を保ってそのまま再利用した。
  子ノード数は 40 弱 → 119。

### src/aircraft_visual.gd（COLOR_0.a = 焼き込み AO の再現）

- 分割時に頂点色を `bake_ao()`: `toLin(rgb)` を線形空間で a 倍し、sRGB に
  戻して alpha=1.0 で保存する。原典 exterior.js の処理順
  （geometryOf の toLin → withAO が線形の間接光を ao 倍）と対応させた。
- 単一クラスのメッシュでも AO 適用のためメッシュを作り直すよう変更
  （以前は material_override のみで色が素通りだった）。戻り値の統計
  （split=追加インスタンス数）の意味は従来どおり。
- 色空間の整理（原典との突き合わせ結果）:
  - 分類 `paint_class()` は従来どおり判定前に線形化しており、原典
    paintClass（線形値で判定）と等価 — ここは既に正しかった。
  - 保存する頂点色は **sRGB 値のまま**にした。理由: (1) verify_visual.gd が
    保存値を build_archer.py の sRGB 定数（紺 0.075,0.16,0.36 等）で固定検証
    する契約があり、線形化するとその 3 件が落ちる。(2) Godot の頂点色パスには
    HTML の geometryOf 相当の線形化段が無く、保存値を線形化すると Phase 2 で
    受入済みの外観（build/phase2-external.png）から機体全体が暗転する。
    代わりに「演算は線形空間で」という原典の順序（分類・AO 乗算）を守った。

run_p4cockpit.gd の主な実測:
- グレアシールドクレスト: 中央 y=0.4795、両端との差 **28.0mm**（24–32mm で合格）、
  中央部 |x|≤0.25 のフラット差 <2mm。panel_wrap_z(0.553)=12mm（関数値）、
  パネル面実測ラップ 3.7mm（面の端 |x|=0.545 地点の値として妥当）。
- 窓開口: 左右とも窓帯三角形の重心が窓内部（縁から 25mm 内側）に 0 件。
  EYE (-0.3,0.62,-0.4) から左 W1・左 W3・右 W2 の各中心への線分は窓帯と
  交差せず、前方視線もクレストを越える。
- AO: archer の body で a<0.75 の頂点 919 件すべてについて、適用後の色が
  `toLin→×a→sRGB` の期待値と ±0.02 以内で一致（919/919）、alpha は全頂点 1.0、
  マテリアルは StandardMaterial3D + vertex_color_use_as_albedo のまま。
- 目視: Xvfb で左席視点を 1 枚撮影し確認した。フロントガラス（中央柱・上弓付き）、
  左窓の大開口、A ピラー、グレアシールドの稜線、パネル全幅が見える
  （Phase 2 の「箱で視界が狭い」状態は解消）。

## 4. 残りの粗さ（正直な申告）

1. **AO の焼き込みは近似**: HTML 版は AO を間接光（天空光・環境反射）にだけ
   掛け、直射光（太陽）は影マップ任せ。頂点色への焼き込みは直射光まで一律に
   暗くするので、日向の陰影は HTML 版よりわずかに平たくなる。StandardMaterial3D
   のまま頂点単位 AO をやる方法はこれしかなく（ao_texture は UV 前提、
   カスタムシェーダ化は本項目の範囲外）、トレードオフとして明記する。
2. **窓帯の開口縁は格子の階段状**（セル中心判定で欠くため、縁は最大で
   z ±15mm / y ±9mm 程度の段差）。縁取り帯（30mm 幅）が上から被るので
   実視では目立たないが、ポリゴンの斜め辺ぴったりではない。
3. **グレアシールドの slope 部は原典フォールバックの癖を継承**: 両端では
   フード斜面が drop しない直線（0.4795 起点）から補間されるため、リップ端
   （0.4515）より斜面の途中（0.4609）がわずかに高くなる。Blender モデル側の
   原典でもフォールバックはこの式であり、実機モデルの断面とは差がある。
4. **チークは原典 profile の近似押し出し**: 原典は下端を panelTopY に
   沿わせた形状だが、本実装は内外面 2 点の panelTopY で近似し、面は平面
   ファン＋リボンで構成した。ベベル（原典 0.005 等）は無い。
5. **座席位置は Phase 2 のまま**（座面中心 z=-0.02）。最新原典の seat() は
   z=-0.58 に置くが、本項目の指示（既存部品は寸法を保って再利用）に従い
   動かしていない。座席とコンソールの前後関係が原典と違う点は残件。
6. 窓ガラスは一様な半透明（alpha 0.10）で、原典 clearGlassMaterial の
   反射・雨滴等の表現は無い。キャビン内 AO（原典の頂点焼き込み遮蔽、
   cockpit.js の skyVis）も未移植 — 内装は一様なマテリアル光のまま。
7. パネルの側面リボン（左右端の封じ）は省略した。端部はグレアシールドと
   チークに隠れる位置だが、真横から覗くとフェイスと背面の隙間が見える。
8. A ピラー・上弓は円柱セグメントの継ぎ目が残る（原典はチューブ曲線）。
