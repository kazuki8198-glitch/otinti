# W22 写真の仕組みとクレジット（R2）

単位：W22（DESIGN 7.2 の W22、5 章の基準 17・25、4.2 の写真の表、8.2、STYLE.md の「写真」）。日付：2026-10-29。

## 1. 結論

- パイロット基礎教材（第 3 版）の写真のうち、合本で使う **51 枚**を新しいファイル `flight-lab/src/book-photos-k.js`（`FL.bookPhotosK`）に入れた。どれも基礎教材のファイル（`flight-lab/kiso/photo/<id>.webp`）と**バイト一致**（再エンコード・再縮小なし。sha256 を記録し、テストで原本と比べる）。id は基礎教材の id のまま（例 `ch00-photo3`）。ほかに **`ch09-photo4` を教科書の `holdShort` に差し替えた**（ID は holdShort のまま。教科書の版は元の写真の下の部分の切り抜きだった）。基礎教材から使う写真は合わせて **52 枚**。
- クレジットは教科書の形 `{author, license, licenseUrl, source}` にした。`source` は章の `photoCreditsHtml` の Commons のファイル名のページ、`license` は元のページの札（`Public domain (PD-self)`・`(PD-user)`・`(PD-user-w)`・`(PD-USGov-NASA)`・`(PD-USGov-FAA)`・`(PD-USGov)`・`(PD-USGov-Military)`・`(PD-USGov-Military-Navy)`・`(PD-USAF)`、`CC0 1.0`、`CC BY n.n`、`CC BY-SA n.n`）。**81 枚すべて（教科書 30・基礎教材 51）を 1 枚ずつ元のページの値と照らした**（ライセンス・作者・元の大きさ）。記録は `reports/W22.photos.json`。
- **加工の表示 `mod` を写真ごとに**付けた（教科書の 30 枚も）。値は `無加工`（縮小と形式の変換だけ）／`切り抜き・縮小`／`注記はパイロット基礎教材（第 3 版）で追加`／`注記は本書で追加` のどれか、2 つ以上は「／」でつなぐ。基礎教材の注記は基礎教材のものとして書き（「本書で追加」と写さない）、基礎教材が切り抜いた 4 枚は `切り抜き・縮小／注記はパイロット基礎教材（第 3 版）で追加`。教科書の 30 枚は元の写真と形を比べ、切り抜いた 16 枚が `切り抜き・縮小`、14 枚（差し替えた holdShort を含む）が `無加工`。
- **条件つき 4 枚**：`ch01-photo4`（737 のフラップとスポイラー）は**使う**（`aero.flaps`）。`ch01-photo2`（ウイングレットが Germanwings の塗装の黄色で一番目立つ）・`ch06-photo2`（Lufthansa の文字とロゴ）・`ch09-photo2`（顔がはっきり写る）は**使わない**。
- **`ch09-photo6`（信号灯）は使わない**：DESIGN 4.2 の表では「使う」だが、管制員の顔がはっきり写っている（STYLE の写真の決まり・基準 17）。DESIGN の表の直しは統合役（6 の 3）。
- 容量：教科書の写真はデコード後 **3,364,306 バイト（3.21 MiB）**で、予算 4.0 MiB の内（教科書 2,303,390・基礎教材 1,060,916）。1 枚の最大は 117,344 バイト（`grassRunway`。上限 122,880）。
- 写真を章に置くのは章の書き手（id で `bk.photo('ch00-photo3')`）。使える id・キャプション・置く節は 4 の表。**`bk.photo` が 2 つめの入れ物と `mod` を読む直しと、ファイルの登録は、W10b か統合役へ**（6）。

### 3.2 重複 3 組

- **停止線**：教科書の `holdShort`（800×687）は、元の `Hold_Short.jpg`（3024×4032 の縦長）の下の部分の切り抜きだった → ID `holdShort` のまま `ch09-photo4` のファイル（560×747、無加工）に差し替えた。キャプション（実線の側＝写真の右で止まる、右の赤地の標示）は全体の写真でも合う。
- **翼端渦**（`vortex` と `ch01-photo3`）・**O-360**（`lycoming` と `ch03-photo1`）：解像度の高い教科書の版を残した（基礎教材の 2 枚は入れない）。`lycoming` のページは GFDL・CC BY-SA 3.0（ライセンスの移行）と **PD-self** の複数のライセンスで、PD-self を選べることを確かめた（クレジットは `Public domain (PD-self)` のまま）。

### 3.4 加工の表示の書き方（STYLE の「書き方は W22 が決める」）

- 基礎教材の写真は、基礎教材のクレジットの文から決めた（テストが同じ規則で確かめる）：「注記」があれば `注記はパイロット基礎教材（第 3 版）で追加`、「トリミング」があれば `切り抜き・縮小`、両方なら「／」でつなぐ、どちらもなければ `無加工`（基礎教材が 560 px に縮小しただけ）。元の写真と形を比べると、トリミングと書いてある 4 枚（`ch02-photo2`・`ch02-photo6`・`ch08-photo1`・`ch12-photo5`）だけが形が違った。
- `ch00-photo4` の Vso などの書き込みは撮影者のもの（元の写真の一部）なので `無加工` で、キャプションに「撮影者が書き込んだ」と書いた。`ch09-photo3` は Commons のファイル自体が切り抜いた派生作品（El Grafo）なので、作者の欄に元の写真と派生の作者を書き、`mod` は基礎教材の注記だけ。
- CC BY-SA の写真には注記がない（基礎教材の決まり 2 のとおり。テストで確かめる）。
