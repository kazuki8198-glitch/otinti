# FLIGHT LAB 使い方

> **本アプリは公開情報を基にした非公式の自主学習用教材です。実機訓練、教官の指示、POH/AFM、SOP、航空法規を優先してください。**
>
> ANA の公式ソフトウェアではなく、認定された訓練装置（FTD など）でもありません。飛行時間・技能・資格（ソロ、ライセンス等）の証明にはなりません。実在の空港・空域・管制では使えません（NOT FOR NAVIGATION）。

---

## 1. 開き方

1. `FLIGHT-LAB.html` を **ダブルクリック**して Chrome で開きます（インストール、ローカルサーバー、npm、Python は不要）。
2. 最初に「はじめに」の注意が出ます。読んだら「理解しました」を押します。
3. インターネットに接続していなくても、教科書・確認問題・Sanford の資料・英語 ATC の練習・飛行訓練（架空の地形）はすべて使えます。
   - Google 3D（任意）だけはオンライン接続と API キーが必要です。

**動作環境**
- Chrome（Windows / macOS）の最近の版。WebGL2 が必要です。
- 想定は Intel Iris Xe 程度のノート PC です。
- 画面が狭いときは F11（全画面）を押すか、右上の「配置」で外部視界と計器の大きさを切り替えます。

**音**
- 右上の「音 OFF」を押すと、エンジン音と失速警報音が鳴ります。
- 英語 ATC の音声は、ブラウザ / OS の音声合成を使います。英語の音声が入っていない環境では鳴りません。

## 2. 画面

### 上段：タブ

| タブ | 内容 |
|---|---|
| 飛行訓練 | 外部視界、G1000 型パネル、右側の訓練課題 |
| カリキュラム | 公開されている訓練の流れに沿った 6 段階の学習順序 |
| 教科書 | 16 章。各章に日本語の説明・英語の用語・例・注意・確認問題 2 問・参考資料 |
| Sanford・交信 | 滑走路、Hot Spot、空域、模式図、英語 ATC の復唱練習 6 場面 |
| 訓練記録 | この端末に保存した練習記録（JSON の書き出しと読み込み） |
| Google 3D 設定 | Google Photorealistic 3D Tiles（任意）の接続 |
| このアプリについて | 注意事項、実装範囲、ライセンス |

### 飛行訓練タブ

**外部視界（上）**
- 景色は教材用の架空の地形です。
- 離着陸は架空の **LAB RWY 36**（磁方位 360、1,200 m × 30 m）で行います。
- 架空の訓練点には色付きの塔が立っています：LAB-A 橙、LAB-B 緑、LAB-C 青、LAB-D 黄、LAB-F 紫。
- 滑走路の左には PAPI（進入角灯）、横には吹き流しがあります。

**G1000 型パネル（下）**
- 「G1000型配置と基本概念を学ぶ教材」です。Garmin 製品の再現ではありません。

- **PFD（左）**
  - 姿勢指示器、バンク目盛、速度テープ（V 速度の目印は教材値）、高度テープ、VSI
  - HSI：HDG バグ（水色）、CDI、TO/FROM、TRK（マゼンタの菱形）
  - ALT SEL、BARO、GS、TRK、風、AOA
  - エンジン状態、予備計器（STBY）
- **オーディオパネル（中央）**
  - COM1/COM2 の MIC 選択、受信のランプ（COM1・COM2・NAV1・NAV2）
  - COM（25 kHz 間隔）と NAV の周波数操作
  - 「送信不可」です。実際の管制にはつながりません。
- **MFD（右）**
  - エンジン欄：出力、回転数、燃料流量、燃料
    - 油圧・油温・EGT・電圧・電流は **「—」（未実装）**。架空の正常値は出しません。
  - MAP ページ：架空訓練点、現在位置、飛行計画、距離、ETE、XTK
  - FPL ページ：飛行計画の表

**訓練課題（右）**
- 課題、レベル、モード（段階課題 / 自由練習）を選びます。
- 目標、全体の進み、条件の連続保持、条件の一覧（✓ / ✗）、ヒント、振り返りが表示されます。

**左上の状態表示**
- スロットル、フラップ、トリム、操縦力（トリムで減らす目安）、ブレーキ、操作補助の状態

## 3. 操作

### キーボード

| キー | 操作 |
|---|---|
| ↑ / ↓ | 機首上げ / 機首下げ |
| ← / → | 左 / 右へ傾ける（バンク） |
| W / S | スロットル 増 / 減 |
| Q / E | ラダー 左 / 右 |
| [ / ] | トリム 機首下げ / 機首上げ |
| F（Shift+F） | フラップを 1 段下げる（上げる）：0° → 10° → 25° → 40° |
| Space | ブレーキ（押している間） |
| C | 視点の切り替え：操縦席 / 機外（後方） |
| P | 一時停止 |
| R | 課題をやり直す |
| H | フード（自由練習のときのみ） |

### 操作補助（教材補助・初期値 ON）

訓練課題の「操作補助の設定」で切り替えます。

- **キー操作の姿勢保持**
  - 空中で、↑↓←→ を押している間だけ目標の姿勢（ピッチ・バンク）が動き、離すとその姿勢を保ちます。
  - キーボードで細かい操作をしやすくするためのものです。
  - 地上では、押している間だけ舵が動き、離すと戻ります。
- **ヨー補助**
  - 空中ではボール（横滑り）を中央へ寄せます。地上では機首の振れを抑えます。
  - プロペラの影響で機首が左へ振られる傾向そのものは残ります。右ラダー（E）で修正してください。
- いずれも**自動操縦ではありません**。HDG バグや ALT SEL には追従しません。実機にはない操作補助です。
- OFF にすると、操縦桿はキーを離すと中立に戻ります。このときトリムの効果がそのまま操縦力に出ます。

### ゲームパッド（標準配置）

| 入力 | 操作 |
|---|---|
| 左スティック | 操縦桿（手前に倒すと機首上げ） |
| LT / RT | ラダー 左 / 右 |
| 右スティック上下 | スロットル |
| A / B | フラップ 下げ / 上げ |
| X | ブレーキ（押している間） |
| Y | 視点の切り替え |
| LB / RB | トリム 機首下げ / 機首上げ |
| START | 一時停止 |
| BACK | やり直し |

- スティックを動かすと、その後 3 秒間はスティックの入力が優先されます（姿勢保持補助は働きません）。
- フライトスティックやスロットル装置は、機種ごとに軸の割り当てが異なります（要確認）。
- ゲームパッドの動作は自動テストの対象外です。

### パネルのボタン

- **PFD の下**
  - ソフトキー：PFD（WIND・ALT UNIT・STD BARO・BACK）、CDI（GPS → NAV1 → NAV2）
  - HDG（− / SYNC / +。Shift を押しながらで 10°）
  - ALT SEL（±100 / ±1000）
  - BARO（±0.01 inHg）
  - CRS
- **オーディオパネル**
  - COM1/COM2、NAV1/NAV2 の切り替え
  - MHz・kHz のつまみ、⇄（使用中と予備の入れ替え）
  - MIC の選択（送信はできません）、受信ランプ
- **MFD の下**
  - MAP / FPL、NORTH UP / TRACK UP、PREV / NEXT LEG
  - RANGE ±
  - D→（架空訓練点への直行。押した位置から新しい区間が始まります）

## 4. 訓練課題

### 12 課題 × 3 レベル

| # | 課題 | 主な内容 | 教科書 |
|---|---|---|---|
| 1 | 直線水平飛行 | 3,000 ft・HDG 360・100 kt、後半は 90 kt | 第 6 章 |
| 2 | 上昇と水平移行 | Vy 76 kt で上昇、3,000 ft で水平 | 第 6・7 章 |
| 3 | 左右旋回 | バンク 20° で HDG 270 へ、HDG 360 へ戻る | 第 8 章 |
| 4 | 低速飛行と巡航への回復 | 65 kt で高度維持（失速警報なし）→ 100 kt | 第 9 章 |
| 5 | 離陸 | 中心線維持、55 kt でローテーション、Vy、1,000 ft AGL | 第 10 章 |
| 6 | 最終進入と着陸 | 3° パスの安定進入、接地帯に接地、停止 | 第 11 章 |
| 7 | 横風下の航跡維持 | 風修正角を取り XTK を保つ | 第 12 章 |
| 8 | 2 地点の目視航法 | LAB-A → LAB-B（色付きの塔と MFD） | 第 12 章 |
| 9 | 目的地変更と再計算 | LAB-F への針路・距離・時間を見積もってから D→ で確認 | 第 12・14 章 |
| 10 | フード下の計器走査 | 外が見えない状態で直進水平と標準旋回 | 第 13 章 |
| 11 | 計器による高度・針路変更 | BARO 30.12 を設定、ALT SEL と HDG を目標にセットして変更 | 第 13 章 |
| 12 | エンジン停止時の滑空 | 76 kt の滑空を作り LAB RWY 36 へ滑空着陸 | 第 14 章 |

### レベル

| | 導入 | 基礎 | 精度 |
|---|---|---|---|
| 高度 | ±150 ft | ±100 ft | ±50 ft |
| 速度 | ±10 kt | ±7 kt | ±5 kt |
| 針路 | ±10° | ±7° | ±5° |
| 保持時間 | 10 秒 | 20 秒 | 30 秒 |
| ヒント | すべて | 最初の 2 つ | なし |

- すべて**仮想教材値**です。実機の速度・許容差は機体ごとに要確認です。
- **評価のしかた**
  - 段階ごとの条件を**すべて同時に**、**連続して**保持時間だけ満たすと、次の段階へ進みます。
  - 条件が 1 つでも外れると、保持時間は 0 に戻ります。
  - 離陸の浮揚や着陸の接地のような「その瞬間」の段階は、その時点の条件で判定します（外れていれば未達成）。
- **どの課題でも未達成になる場合**
  - 機体損傷
  - 滑走路逸脱
  - 想定外のエンジン停止
  - 制限時間超過
- **自由練習**：評価なしで、課題の状況や開始位置から自由に飛べます。
  - 開始位置：LAB RWY 36、LAB 空域上空、最終進入、Sanford 上空
- 終わると**振り返り**が出ます。
  - 段階ごとの所要時間、リセット回数、最大のずれ、接地記録、次回のポイント
  - メモを書いて保存できます。

### 接地の判定（教材値）

| 判定 | 基準 |
|---|---|
| ハードランディング | 接地直前の降下率 600 fpm 超 |
| 機体損傷 | 1,000 fpm 超、または大きく傾いた接地 |
| 着陸課題の合格 | 導入 600 fpm 以下・接地帯 0〜750 m・中心線 ±8 m など。精度では 300 fpm・150〜450 m・±3 m |

## 5. 教科書・カリキュラム・Sanford・交信

**教科書・カリキュラム**
- 章を開くと「読んだ」印が付きます。確認問題の正誤は**この端末のブラウザにだけ**保存されます。
- 参考資料のリンク（FAA、ANA、Piper、Garmin など）はオンライン時に開けます。

**Sanford・交信**
- 公開情報の要約と、出典へのリンクがあります。
  - 「事実」「教材の要約」「未確認・要確認」に分けて表示します。
- 空港の図は**模式図・NOT FOR NAVIGATION** です。
- **英語 ATC**
  - コールサインは架空の「Archer Seven Lima Alpha」です。
  - 手順：▶ 音声で聞く → 正しい復唱を選ぶ → 答え合わせ（理由と「Say again」などの確認方法）
  - 音声認識・録音・送信はしません。

## 6. 訓練記録

- 段階課題が終わると自動で保存されます。自由練習は「記録を保存」で保存します。
- 保存先はこのブラウザの localStorage だけです。サーバーには送りません。
- **保存するもの**
  - 課題、日時、レベル、モード、達成度、条件内の時間、練習時間
  - 高度と速度の履歴、イベント（接地など）、メモ
- **保存しないもの**
  - API キー、Google のトークンや地形データ、個人情報
  - メモに API キーやトークンらしき文字列を貼った場合は、自動で削除します。
- **本記録は教材シミュレータの練習記録です。正式な飛行日誌（logbook）ではなく、飛行時間として扱えません。**
- 「JSON に書き出す」でファイルに保存できます。「JSON から読み込む」で別の端末の記録と統合できます。
  - 読み込み時は、知らない項目を捨てる、数値を検査する、などの処理をします。

## 7. Google 3D（任意）

Sanford 周辺（表示原点 約 28.777, −81.238 を中心に半径約 12 km）の外部景観を、Google の公式 **Map Tiles API（Photorealistic 3D Tiles）** で表示できます。

1. Google Cloud で Map Tiles API を有効にし、API キーを作ります。
   - 請求先アカウントが必要です。
   - キーには **API の制限（Map Tiles API のみ）** を設定してください。
   - Google Cloud で**割り当て（クォータ）の上限**も設定してください。
2. 「Google 3D 設定」タブでキーを入力して「接続」を押します。
3. 「Sanford 上空へ（自由練習）」で Sanford の上空に移動します。

**キーの扱い**
- キーは**メモリだけ**に保持します。localStorage・記録・JSON・URL には保存しません。
- 再読み込みや「切断（キーも消去）」で消えます。
- キーは tile.googleapis.com へのリクエストにだけ付けて送ります。

**使い方の決まり**
- 使うのは Google の公式 Map Tiles API だけです。
- Street View 画像の取得・スクレイピング・保存、非公式 API の利用はしません。
- タイルは表示に必要な分だけ読み、使わなくなったらメモリから捨てます（保存・事前取得はしません）。
- 表示中は画面左下に **Google Maps** の表記と、タイルのデータ提供元（著作権表示）を出します。

**表示だけで、判定には使わない**
- Google のデータは外部景観の表示だけに使います。
- 建物・地形との衝突判定、実在空港への接地、滑走路の抽出はしません。
- 空域・NOTAM・飛行計画・管制もありません。
- 機体は教材の平らな地面（55 ft）の上を飛びます。

**高さ合わせ**
- Google の高さ（楕円体高）と教材の地面の差は、原点付近のタイルから推定します。
- ずれて見えるときは「−5 m / +5 m」で調整できます。

**課金**
- 接続のたびにルートのタイル要求が発生し、Google Maps Platform の課金対象になります（セッションは約 3 時間）。
- 料金・無料枠・上限は Google の最新の案内を確認してください。

**file:// で開く場合の注意**
- ページを `file://` で開くと、ブラウザは Referer（ページのアドレス）を送りません。そのため、キーの「ウェブサイトの制限（HTTP リファラー）」は使えません。
- API の制限とクォータの上限で守ってください。
- https で配信されたページ（例：GitHub 経由の配信）から使う場合は、ウェブサイトの制限も設定できます。

**エラーの例**
| 表示 | 主な原因 |
|---|---|
| 403 | キーの誤り、API 未有効、請求先未設定、制限の不一致 |
| 429 | 上限超過 |
| 接続できません | オフライン、ネットワークの制限 |

いずれの場合も、教材と飛行訓練はそのまま使えます。

## 8. 困ったとき

| 症状 | 対処 |
|---|---|
| 外部視界が出ない | WebGL2 が無効の可能性。Chrome の設定でハードウェア アクセラレーションを有効に。計器と課題は使えます |
| 機首が左に振られる | プロペラの影響（教材モデルでも再現）。右ラダー（E）で修正。操作補助のヨー補助を ON に |
| 音が出ない | 右上の「音」を ON に。英語 ATC は OS に英語の音声が必要 |
| 記録が残らない | プライベートモードなどで localStorage が使えない。JSON の書き出しは使えます |
| 画面が狭い | F11 で全画面、「配置」で計器と外部視界の比率を変更 |

## 9. 開発者向け

```
flight-lab/
  src/            index.html, style.css, physics.js, avionics.js, curriculum.js, sanford-course.js,
                  training.js, scene.js, google3d.js, app.js
  vendor/draco/   Draco デコーダー（Apache-2.0、three.js r160 同梱版）
  test/           flight.test.mjs, avionics.test.mjs, browser.test.mjs, bot.mjs（テスト用の操縦役）, fixtures/
  build.mjs       src を 1 つの HTML にまとめる → outputs/FLIGHT-LAB.html
  outputs/        FLIGHT-LAB.html と文書
```

- **ビルド**：`node build.mjs`
- **テスト**：`node --test test/flight.test.mjs test/avionics.test.mjs test/browser.test.mjs`
  - ブラウザテストには Playwright が必要です。見つからないときはそのテストだけ省略されます。
- **テスト用の Google タイル**
  - `test/fixtures` の偽タイルセットを使います。Google のデータではありません。Draco 圧縮・テクスチャ付きの 30 km 四方の平面です。
  - これを tile.googleapis.com の代わりに返して、Worker での展開・描画・帰属表示・キーの扱いを確認します。
  - 本物の Google の応答での確認は、キーがないため未実施です。
