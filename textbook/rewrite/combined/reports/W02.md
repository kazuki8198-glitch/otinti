## 2. したことと理由

### 2.1 読み込みの列を 1 つに（決まり 7）

- 列は `flight-lab/src/modules.mjs` の `MODULES` だけ。FLIGHT LAB のビルドは全部を、この順で読む。開発用 `src/index.html` も同じ順の `<script src>`（テストで一致を確かめる）。
- 各製品は**読まないもの**を理由つきで書く：
  - TEXTBOOK（`textbook/build.mjs` の `FL_LEAVE_OUT`）：`kiso/kiso-data.js`・`quiz.js`・`radio.js`・`ui.js`・`acmesh.js`・`scene.js`・`google3d.js`・`pages.js`・`app.js`
  - CADET（`cadet/build.mjs` の `FL_LEAVE_OUT`）：`book-photos.js`・`kiso/kiso-data.js`・`ui.js`・`scene.js`・`google3d.js`・`pages.js`・`app.js`
  - FLIGHT LAB の Node のテスト（`flight-lab/test/load.mjs` の `NODE_LEAVE_OUT`）：`book-photos.js`・`kiso/kiso-data.js`・`acmesh.js`・`scene.js`・`google3d.js`・`pages.js`・`app.js`（今までのテストと同じ組）
- `without()` は、列にない名前（改名・削除されたファイル）や理由のない項目をエラーにするので、読まないものの列が古くなってもすぐわかる。
- 新しいファイル（W06 の `book-jur.js`、W09 の `book-0.js` など）は `MODULES` に 1 行足すだけで 3 製品とテストに入る。読ませない製品はその製品の `FL_LEAVE_OUT` に理由つきで足す（DESIGN 6.3：CADET は `book-gates.js`・`book-7.js`・`book-photos*.js`・`quiz-jcab.js` を足す）。TEXTBOOK は `build.test.mjs` の `14` を意図して直す。
- CADET の読み込みの順が 1 か所だけ変わった：`acmesh.js` が `syllabus.js` の次から `radio.js` の次へ（共有の列の順）。`acmesh.js` は読み込みのときに他のファイルを使わない（`FL.physics` の参照はコメントだけ）ので、動きは変わらない。CADET のテストは全部通る。
- CADET の本を読むテスト（content・ai・school・english・career-run・cockpit-talk）は、ゲームと同じ列（`GAME`）を読むようにした。今までは本のファイルだけ・順も少し違う列を手で書いていたので、`book-0.js` などが入ったときにテストだけ古い本を読む恐れがあった。

### 2.2 容量（決まり 8・DESIGN 8.2）

- `flight-lab/build.mjs` に `MAX_BYTES = 12 * 1024 * 1024`（12,582,912 バイト）を戻した（3D 表示の v2.4 のブランチ `abbf2d0` と同じ値。そこでは `>=` で止めていたが、ここでは「上限ちょうどまでは可」の `>`）。超えるときはファイルを書かずにエラー。
- 今の大きさ：FLIGHT-LAB.html 9,395,251 バイト（8.96 MiB、余り 3,187,661 バイト）、CADET.html 9,196,508 バイト（上限 15 MiB）、TEXTBOOK.html 4,409,254 バイト。

### 2.3 「（別の章）なし」と「行き先のないリンクなし」（決まり 6）

3 製品とも、出力の HTML ファイルには FLIGHT LAB のコード（`fix()` の中の文字「（別の章）」）がそのまま入るので、ファイルの文字ではなく**読者に見えるもの**を、各製品が描くとおりに作って調べる。

- FLIGHT LAB（`flight.test.mjs`）：全節の本文と題、章末（要約・例・注意・確認問題の問と選択肢と理由）、学科テストの全問。選択肢は FLIGHT LAB が `BK.fix` を通さずに出すので、そのまま調べる。リンク：`data-sec`・`data-lesson`・`data-calc`・本文の `<a href>`（https）・章末の課目と出典・課目の `book`・学科テストの `book`・英語交信の各段階の `sec`。
- TEXTBOOK（`content.test.mjs`）：全文のページ（`allHtml`）、前後の節つきの全節、目次、検索の結果、全問の答え合わせの文。リンク：`data-go`・`data-sec`・`data-jump`・ページの中の `href="#…"`（ページにある id）・`data-lesson`・`data-calc`・外部の `<a href>`（https）。
- CADET（`content.test.mjs`）：全節の HTML・文字・要約・要点。リンク：`data-sec` は CADET の本にある節だけ、`data-sec` のない「→」（`span.bk-see`）はゼロ、`<button>`・`data-lesson`・`data-calc` はゼロ、`<a>` は https。筆記試験（`quiz.js`）の `{ch:}` は全部 CADET の本にある章を指す（ない章は `content/school.js` が黙って「教科書」にしてしまうため）。
- **見つかった誤り（新しい）**：CADET の `comm.practice`（第 1 部 `radio5`）の最後の項目「チェアフライング」が「（（別の章））」と出る。`book-comm.js` の `（{ch:sim}）` が、CADET の外す章 `sim` を指しているため。DESIGN の誤りの一覧（10 章）にはない。中身を変えない単位なので直さず、テストでは既知の 1 件として名前を挙げて許し（`KNOWN_OTHER_CHAPTER`）、ほかの節に出たら失敗する。直ったら診断の行（「take it off」）が出るので、そのときに一覧から外す。下の 5 の依頼 1。

### 2.4 CADET の AI 教官の目次（DESIGN 6.3）

### 2.5 学習記録の画面とメニュー（DESIGN 6.4）
