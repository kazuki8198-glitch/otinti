# TEXTBOOK — FLIGHT LAB の教科書だけを読むページ

FLIGHT LAB の教科書（全 7 部（序部と第 1〜6 部）・34 章・208 節・図 174・写真 50 枚。第 1 部の扉と付録「JCAB 学科の道」のページつき）を、シミュレータやゲームとは別に、**教科書だけを読むための 1 つの HTML ファイル**にしたものです。

- 出力：`outputs/TEXTBOOK.html`（約 7.1 MB の 1 ファイル。写真は WebP で中に入れています）
- ダブルクリックで開けて、オフラインですべて読めます。外部のスクリプト・スタイル・フォント・画像は使っていません。
- 写真は、パブリックドメイン（NASA・FAA・NOAA など米国政府の著作物）と CC0・CC BY・CC BY-SA のものだけです。クレジットは各写真の説明と [`../flight-lab/PHOTO-CREDITS.md`](../flight-lab/PHOTO-CREDITS.md) にあります。
- 章末の「出典・参考資料」のリンクだけは外部のページです。クリックしたときだけ、新しいタブで開きます。

## 操作

- **目次**：左（スマホでは上）に、部 → 章 → 節。いま開いている節は色がつき、読んだ節には ✓ が付きます。「目次」ボタンで隠せます。
- **前の節・次の節・章のはじめへ**：各節の下のボタンで移ります。
- **URL**：`TEXTBOOK.html#aero.lift` のように、節の ID でその節を直接開けます。節を移ると URL も変わります。
- **検索**：上の欄に言葉を入れると、その言葉がある節が目次の代わりに並びます（大文字・小文字は区別しません）。選ぶと、本文の中の言葉に印が付きます。章末（用語・例・注意・確認問題・出典）に当たったときは、その章の最後の節が開きます。図の中の文字も検索の対象ですが、図の中には印を付けません。
- **確認問題**：選んで「答え合わせ」を押すと、正誤と理由が出ます。
- **計算機**（横風・偏流・燃料・重量と重心など 7 種類）：本文の中でそのまま動きます。
- **全文**：全 34 章を 1 ページに続けて出します（`#all`。印刷用。章ごとに改ページ）。印刷するときは「考えてみよう」が開いた状態で印刷されます。
- **表示**：自動（OS の設定）→ 明るい → 暗い の順に切り替わります。図と計算機は、どちらの表示でも暗い板の上に出ます。
- **A− / A＋**：文字の大きさを変えます。

読んだ印・確認問題の結果・表示の設定は、このブラウザの localStorage にだけ保存します（キーは `textbook.` で始まります）。保存を許さないブラウザでも読めます。

## 作り方とテスト

npm の部品は使っていません（`npm install` は不要です）。Node.js 20 以上で動きます。

```sh
cd textbook
npm run build   # outputs/TEXTBOOK.html を作る（このコマンドだけがこのファイルを書きます）
npm test        # 中身・ビルド・ブラウザのテスト（node --test、ブラウザは一度に 1 つ）
npm run shots   # 画面の絵を docs/ に撮る（npm test には入っていません）
```

- `build.mjs`：`FL_MODULES` の順に FLIGHT LAB のファイルを入れ、このページのスクリプトと CSS を足して 1 つの HTML にします。同じソースからは毎回同じバイト列になります（日付や git のハッシュは入れません）。
- `src/index.html`・`src/style.css`：ページの骨組みと見た目（FLIGHT LAB の `.bk-*` などの見た目を、明るい表示と暗い表示の色で書き直したもの）。
- `src/render.js`：章・節 → HTML の文字列（DOM を使わないので、Node のテストでも確かめます）。
- `src/page.js`：目次・検索・札への置き換え・計算機・確認問題・保存・印刷など、DOM につなぐ部分。
- `test/content.test.mjs`：7 部（序部 p0 と第 1〜6 部。どの部も空でない）・34 章・208 節、章の並び、全節が描けること、章末の数（確認問題 213・用語 741・例 115・注意 94・出典 446・飛行課目 75）、章末の「この章の日米の違い」（日米の囲みのある章だけ。まとめの章は除く）、図 174・写真 50、第 1 部の扉と「JCAB 学科の道」のページなど（数は `test/load.mjs` の `COUNTS` に 1 か所でまとめています）。
- `test/build.test.mjs`：1 ファイル・外部の読み込みなし・全スクリプトの構文・19 ファイルの順番・注意書き・同じ出力になること。
- `test/marks.test.mjs`：節の題の横の範囲の札・発展の札・由来の行（`FL.book.secMarks`）と、章末の説明してみよう（`FL.book.writtenHtml`。答えはボタンで開く・検索で見つけた答えだけ開く・印刷で全部開く）。
- `test/use.test.mjs`：節の題の下の使う場面の札（課目・まとめ・JCAB の科目。このページには学科テストがないので出ない）と試験の項目の注記（JCAB の出題範囲参考の見出し・FAA の ACS の知識の項目。ボタンで開け閉め・印刷で開く）、札の課目を押すと札の下に課目の説明。
- `test/photos.test.mjs`：写真の 2 つの入れ物（教科書の `book-photos.js`・基礎教材の `book-photos-k.js`）の形・原本とのバイト一致・加工の表示・置く節・容量・クレジットの一覧と元のページの記録。
- `test/egov.test.mjs`：e-Gov の条文の写し。
- `test/browser.test.mjs`：すでにこの環境にある Playwright で、`file://` から開いて操作を確かめます（http(s) の要求はすべて止めて数え、0 件であること）。Playwright が見つからないときは skip します。探す順番は、環境変数 `PLAYWRIGHT` → `require('playwright')` → `/opt/node22/lib/node_modules/playwright` です。
- テストとスクリプトがファイルを書くのは `test-output/`（と、`npm run shots` の `docs/`）だけです。

## FLIGHT LAB から読み込んでいること

教科書の中身は `../flight-lab/src` のファイルを、ビルドのときにそのまま読み込んでいます（コピーしていません）。列は FLIGHT LAB の共有の列 `flight-lab/src/modules.mjs` から作り、読まないものを `build.mjs` の `FL_LEAVE_OUT` に理由つきで書いています。今は次の 19 ファイルを、この順番で入れます。

`physics.js` → `avionics.js` → `sanford-course.js` → `school.js` → `syllabus.js` → `book-figs.js` → `book-core.js` → `book-terms.js` → `book-jur.js` → `book-photos.js` → `book-photos-k.js` → `book-1.js` → `book-0.js` → `book-2.js` → `book-comm.js` → `book-3.js` → `book-4.js` → `book-5.js` → `book-gates.js`

- `physics.js` が先にないと、book-1/3/4/5 が読み込みのときに止まります。
- `book-comm.js` の 5 章（無線）は「人間の能力と判断」の章（`hf`）の前に入るので、`book-2.js` の後に読みます。
- `book-0.js` は序部（p0）を `FL.book.addPart` で第 1 部の前に足します。序部の章は `intro`（`book-1.js`）と `sim`（`book-5.js` が `aero` の前に入れる）です。
- `school.js`・`syllabus.js` は、飛行課目の名前を出すために入れています。
- `book-gates.js` は、部のまとめの章（今は第 1 部の `g1`。次の部の最初の章の前に入る）と、付録のページ「JCAB 学科の道」の中身です。部の扉（今は第 1 部）は `book-core.js` の部のデータで、目次の部の名前の下から開きます。学科テスト（`quiz.js`）は読まないので、扉の課目の表に学科テストの列は出ません。
- `book-photos-k.js` は、合本が使う基礎教材の写真（51 枚、原本のファイルとバイト一致）です。FLIGHT LAB のページは同じ写真を原本のデータから読みますが、このページは原本を読まないので、写真をすべて持つファイルをそのまま入れます。
- `book-terms.js`（用語の表 `FL.terms`）と `book-jur.js`（日米の対照データ `FL.jur`）はデータだけのファイルです。合本の検査の道具（`textbook/rewrite/combined/tools/`）はこの列で本を読みます。

教科書を直すときは FLIGHT LAB のファイルを直し、ここで `npm run build` をし直してください。
