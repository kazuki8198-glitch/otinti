## 2. したことと理由

### 2.1 使う場面の札（DESIGN 3.2 の `use`）

形：`使う場面：課目 a6・a7・a8／学科テスト「飛行の原理」／まとめ 1／JCAB 航空工学`。種類ごとに 1 回、この順。

- **データのリンクから自動で作る**（DESIGN「課目のリンクと学科テストのリンクから自動で作り、足りない分だけ手で書く」）：
  - 課目：`FL.syllabus` の課目のうち `book` にその節があるもの（課程表の順）。
  - 学科テスト：`FL.quiz` の分野のうち、`book` がその節か、問の 5 つめ `meta.sec` がその節のもの。TEXTBOOK は `quiz.js` を読まないので、TEXTBOOK の札には出ない（学科テストのページがない）。
  - まとめ：部のまとめの章 `gN` の節の中の `bk.see`（`data-sec`）と、章末の問の `sec` がその節を指すもの。まとめの章の自分の節には出さない。
  - JCAB：節の `jcab` の見出しが属する科目。科目の名前と見出しの分け方は `FL.book.JCAB_ROAD`（`book-gates.js`、「JCAB 学科の道」と同じ表）から取るので、札と道が食い違わない。科目名は JCAB の書き方（航空工学・航空気象・空中航法・航空通信・航空法規・計器飛行一般。判断 3 の補足）。
- **節の `use` で足す**：`'課目 k1'`（課目の ID、「・」で区切って複数可）、`'まとめ 1・まとめ 6'`、`'JCAB 航空工学・空中航法'`。今のデータの `'JCAB 工学'` は道の科目の短い名前として読み、`航空工学` と出す（`'工学（無線工学）'` は `航空工学（無線工学）`）。それ以外の文字は、そのまま最後に出す。
- **リンクは行き先があるときだけ**（決まり 6・13）：課目と学科テストはその製品にあるものだけ、まとめはその章が本にあるときだけ（今は `g1`。`まとめ 2`・`まとめ 4`・`まとめ 6` は `g2`〜`g6` ができると、データを書き直さずに現れる）、JCAB は付録「JCAB 学科の道」がその節を並べているときだけリンク（今は序部と第 1 部：`upTo: 'p1'`。第 2 部以降の節の JCAB は文字だけ）。
- **リンクの動き**：
  - FLIGHT LAB：課目・学科テストは課程表の画面でそのカードを選んだ状態で開く（ブリーフと「開始」「テストを始める」のボタン。札から直接は飛ばない。`bk.sim` のボタンは今までどおり課目を始める）。`まとめ 1` は節を開く、`JCAB …` は付録のページを開く。
  - TEXTBOOK：課目は札の下に、課目の札（`.bk-lesson`）と同じ説明（目的・なぜ・合格の目安・FLIGHT LAB を開くリンク）を出す。課目の札にしなかったのは、`FLIGHT LAB の課目『…』` の長い札が 1 行の札を崩すためと、`COUNTS` の課目の札の数を変えないため。`まとめ 1` と JCAB は、このページの節とページのリンク（`button[data-sec]`・`button[data-page]`）でそのまま動く。
- **置き場所**：題の横の範囲の札・題の下の由来の行の、さらに下（`secMarks` の中。FLIGHT LAB と TEXTBOOK が同じ HTML を置く）。DESIGN 3.2 の「節の形」は「ねらい → 使う場面の札」の順だが、ねらいは本文（`bk.aim`）の中にあり、本文を製品ごとに割って差し込むのは壊れやすいので、ねらいの直前（題の部品の最後）に置いた（6 の 2）。

今の本（7 部・34 章・208 節）で札が出る節：**149**（序部 12・第 1 部 108・第 2 部 15・第 3 部 5・第 4 部 5・第 5 部 3・第 6 部 1）。うち課目 48・学科テスト 71（FLIGHT LAB）・まとめ 55・JCAB 85（85 節とも道へのリンク）。第 2 部以降は課目と学科テストのリンクから出ている（節のデータ `use` は R3 の章の単位が書く）。

### 2.4 CADET

CADET は `secMarks` を呼ばず、節の本文（`h`）だけを読むので、札・注記はもともとゲームの本・教官の台詞・AI 教官の目次に出ない。テストで、ゲームの本の全節の HTML・文・要約・要点、章と節の一覧、AI 教官の目次に札・注記の言葉とクラスがないことを確かめた。安全網として、本文に札が貼られた場合は `filterHtml` が `bk-marks`・`bk-use`・`bk-exam` を入れ子ごと外す（テストで貼って確かめた。外したあとの要約は本文の文だけ）。まとめの章と第 7 部はもともと CADET の本にないので、`まとめ N` のリンクも出ない。

### 2.5 打ち間違いを隠さない

`use`・`jcab`・`faa` が文字の配列でない、`jcab` が見出しの ID の形でない、`faa` が ACS の符号の形でない、`use` の `課目 x` が課程表にない、`まとめ N` が 1〜7 でない、`JCAB 科目` が道の科目にない — どれも `secMarks` が止まる（W10b の `scope`・`from` と同じ考え）。全節を描くテストがあるので、データの打ち間違いはテストで見つかる。台帳にない見出し・ACS の要素は `check-maps.mjs` が数える（製品のテストは台帳にある見出しの番号を照らす）。

### 2.6 W10b のテストの 1 行

`flight.test.mjs` の「book: FL.book.secMarks — …」は、`scope`・`from`・`deep` のない節で `secMarks` が空の文字列であることを求めていた。札は課目・学科テストのリンクから出るので（例 `ops.trim`：課目 a1・学科テスト「基本操縦と離着陸」）、その行を「範囲の札・由来の行が推測で出ない」（`data-scope`・`bk-scope`・`bk-from` がない）に直した。決め打ちの数ではない（`TEST-CONSTANTS.md` の行は 7 の 5）。
