# CADET（Godot ネイティブ移植版）v1.0.1

パイロット訓練生シミュレーター「CADET」の、HTML 単一ファイル版から Godot 4 への
ネイティブ移植版です。翔洋航空訓練所で訓練生として学び、操縦・筆記試験・無線・
判断の 4 能力を育てて卒業を目指します。本書は配布 zip（CADET-godot-v1.zip）に
同梱されています。

## 起動方法

1. zip を任意のフォルダに展開します（展開せずに exe を直接実行しないでください）。
2. フォルダ内の **CADET.exe** をダブルクリックします。インストールは不要です。

### 未署名 exe への Windows の警告について

この exe はコード署名をしていないため、初回起動時に Windows SmartScreen の
「Windows によって PC が保護されました」という画面が出ることがあります。
配布元（この zip を渡した人）に心当たりがある場合のみ、次の手順で起動できます。

1. 警告画面で **「詳細情報」** をクリックします。
2. 表示される **「実行」** ボタンをクリックします。

これは未署名の実行ファイル全般に対する Windows の標準動作で、本ソフト固有の
問題ではありません。心当たりのない入手経路の場合は実行しないでください。

## 動作環境

- Windows 10 / 11（64 ビット）
- Intel Iris Xe 級の内蔵 GPU を想定（専用 GPU 不要）
- キーボード必須。ゲームパッド／ヨーク／ペダル／スロットル・クアドラントは任意
  （F12 の設定画面で機器ごとに割り当て可能）
- オフラインで動作します。ただし **AI 教官**（自由質問）だけはインターネット接続と
  Anthropic API キーが必要です（下記「設定ファイル」参照）。キー未設定の場合は
  台本式の会話に自動でフォールバックします。

## はじめ方（タイトル画面）

起動するとタイトル画面が表示されます。ボタンはマウスでクリックします。

| ボタン | 内容 |
|---|---|
| キャリアをはじめる | 訓練生としてのキャリアを最初から開始（入所の会話から始まります） |
| つづきから | セーブデータがあるときだけ表示。前回の続きを再開します |
| フリー飛行 | 滑走路上でエンジン始動済み・すぐ離陸できる状態から自由に飛行 |
| レッスンを選ぶ | 飛行レッスン（a1、t1〜t3、航法・計器・夜間ほか）の一覧から開始 |

飛行を始めた直後は、画面左上に **ガイド** が常時表示されます（今やること＋
主要キー）。地上では「Shift+B でパーキングブレーキ解除 → R 長押しで
スロットル全開 → 55 kt で S を引いて離陸」の順に案内します。
飛行中に **Esc** を押すとタイトル画面に戻れます。

※ v1.0.0 ではタイトル画面がなく、起動直後にフリー飛行へ入って
　 操作方法も表示されませんでした。v1.0.1 で入口を実装し直しました
　 （詳細は FIX-REPORT.md）。

## 操作方法

### 飛行

| キー | 動作 |
|---|---|
| W / S | 操縦桿（機首 下げ / 上げ） |
| A / D | エルロン（左 / 右ロール） |
| Q / E | ラダー（左 / 右） |
| ↑ ↓ ← → | 操縦桿（矢印キー、ピッチはスプリング戻り） |
| R / F | スロットル 上げ / 下げ（Shift+R = 全開、Shift+F = アイドル、PageUp/PageDown も可） |
| B または Space | ブレーキ（押している間だけ効きます） |
| Shift+B | パーキングブレーキ セット / 解除（エプロン開始時はセットされています。画面下に PARK と出ているときは、まずこれで解除してください） |
| V | フラップ下げ（Shift+V = フラップ上げ） |
| G | ギア 上げ / 下げ（格納式の機体のみ） |
| T | エレベータートリム（押し続け、Shift+T = リセット） |
| Z / X | ラダートリム 左 / 右 |
| [ / ] | 左 / 右エンジンのフェザー（Shift = 再始動、双発機のみ） |
| L | 水平に戻す |
| U | オートラダー切替 |
| Enter | チェックリストを次へ進める |
| 1〜3 | 無線（ATC）への回答の選択 |

### 視点・モード切替

| キー | 動作 |
|---|---|
| C | コックピット視点 ⇔ 外部視点 |
| Esc | タイトル画面に戻る |
| 1 / 2 | フリー飛行（滑走路 / エプロン）を開始し直す（飛行中のショートカット。通常の入口はタイトル画面です） |
| 3〜6 | レッスン a1 / t1 / t2 / t3 を開始 |
| N | レッスン終了後、フリー飛行に継続 |
| F2 | オートパイロット 接続 / 解除（HDG バグ＋選択高度へ） |
| F5 / F6 | G1000 方位（HDG）バグ − / ＋ |
| F7 / F8 | G1000 選択高度 − / ＋ |
| F9 / F10 | G1000 レンジ − / ＋ |
| F11 | 機体切替（Archer → Seminole → Arrow → …） |
| ゲームパッド | 左スティック = ヨーク、右スティック X = ラダー、A = ブレーキ、Y = フラップ下げ、X = フラップ上げ |

### キャリア・レッスン・会話

| キー | 動作 |
|---|---|
| F3 | キャリア開始 / 次の予定へ進む（レッスン・試験・ドリルは予定に従って開始） |
| 1〜4 | 筆記試験の回答（試験中）／ドリルの回答 |
| J | 教官との会話（transit）を開く |
| Enter | 会話を進める |
| 1〜6 | 会話の選択肢 |

### 徒歩モード

| キー | 動作 |
|---|---|
| F4 | 徒歩モード 切替（学園・寮・管制塔・格納庫を歩けます） |
| W / A / S / D | 前 / 左 / 後 / 右へ移動（壁にぶつかります。段差 0.45 m まで自動で登ります） |

### EFB・リプレイ・設定

| キー | 動作 |
|---|---|
| Tab | EFB タブレット 開 / 閉（空港図・重量重心計算・チェックリスト） |
| P | リプレイ 開始 / 終了（直前の飛行を再生。飛行中は記録されます） |
| C（リプレイ中） | リプレイカメラ切替（タワー / チェイス / ウィング） |
| F12 | 設定パネル 開 / 閉（画質プリセット・音量・AI キー・デバイス割り当て） |

レッスン終了時にはデブリーフ（採点内訳）と高度・速度のプロファイルグラフが
表示されます。フライト記録は CSV / GPX として書き出されます（保存先は下記
セーブフォルダ）。

## セーブと設定ファイルの場所

Godot の `user://` が実パスとして割り当てられる場所に保存されます。

```
%APPDATA%\Godot\app_userdata\CADET (Godot port)\
```

| ファイル | 内容 |
|---|---|
| `cadet_save.json` | セーブデータ（キャリア進行・成績・会話状態） |
| `cadet_settings.cfg` | 設定一式（下記） |
| `logs\godot.log` ほか | 起動ログ（先頭に版数が出力されます） |

`cadet_settings.cfg` はテキスト形式で、F12 の設定パネルからも編集できます。

- `[display] quality` — 画質プリセット（`low` / `medium` / `high`。影・フォグ・雲の効きが変わります）
- `[audio] master_volume` — マスター音量（0.0〜1.0）
- `[ai] api_key` — AI 教官用の Anthropic API キー（任意。自分のキーを自分の責任で）
- `[devices]` — ヨーク／ペダル／スロットル等の機器別割り当て（F12 パネルで設定）

最初からやり直したい場合は、本ソフトを終了した状態で `cadet_save.json` を
削除してください（設定は残ります）。

## ログと異常終了について

- 画面右下に版数（例: `CADET v1.0.1`）が常時表示され、起動ログの先頭にも
  同じ版数と Godot のバージョンが出力されます。
- 異常終了した場合も、直前までのログは上記 `logs` フォルダに残ります
  （Godot 標準のファイルログ。報告の際は `godot.log` の末尾が手がかりになります）。
- Godot 本体がクラッシュダンプを出す場合は同フォルダ配下に記録されます。

## 既知の制限（v1）

- **キャラクター**は本移植の対象外で、人物は基礎フィギュア（色分けされた人型＋
  名前表示）です。HTML 版の作り込まれた人物表現とは異なります。
- **音声認識は未搭載**です。HTML 版にあった音声での読み上げ復唱・音声質問は
  使えません（無線への回答はキー選択式です）。
- 内装は基礎レベルです（壁・家具・塔の階段はありますが、ドアの開閉アニメーション、
  学園棟の 2 階・屋上への階段はありません）。家具にはぶつかりません（壁のみ）。
- 雲は静的配置で、漂ったり天候と連動したりしません。地面のテクスチャは近景で
  繰り返し感が出る場合があります。
- AI 教官は会話 UI に未統合です（接続口とキー設定のみ用意。会話は台本式が本体です）。
- リプレイは位置と姿勢のみの再生で、ギアやフラップの見た目は連動しません。
- デバイス割り当ては軸の役割分担までで、スロットル／プロペラ／ミクスチャーの
  軸は操縦系への接続が未完です。軸番号の変更は設定ファイル経由のみです。
- セーブデータは HTML 版と互換性がありません（新規スタートです）。

## 位置づけ

HTML 版は無変更のまま保険として残されています。本版の問題で遊べない場合は
HTML 版（CADET.html）を使ってください。
