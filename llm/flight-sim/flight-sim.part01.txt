        <h3>「中立」ってどこ？</h3>
        <p>キーを<b>押している間だけ</b>操縦桿（操縦かん）が動き、<b>離すと中央（中立）に戻ります</b>。スマホでは左下のスティックから指を離すと中立です。計器パネル右の「操縦桿の位置」で、点が中心で緑になっていれば中立です。</p>
        <p><b>操縦アシスト ON</b>（おすすめ）：中立にすると、機体は自動で翼を水平にし、上昇も降下もしない水平飛行に戻ります。傾けたいときは押し続け、戻したいときは離すだけ。</p>
        <p><b>操縦アシスト OFF</b>：本物の飛行機と同じで、中立にしても傾きや機首の向きは<b>そのまま残ります</b>。水平に戻すには反対方向のキーを少し押します。困ったら <kbd>L</kbd>（スマホは「水平」ボタン）で自動的に水平飛行に戻せます。</p>
        <h3>PS5 コントローラー（DualSense）</h3>
        <p>USB ケーブルか Bluetooth でパソコンにつなぎ、ボタンをどれか押すと認識されます（Chrome・Edge 推奨）。</p>

        <h3>離陸の手順</h3>
        <ol><li>スロットルを 100% にする（<kbd>R</kbd> 長押し）</li><li>速度計を見て、機体ごとの離陸速度（練習機なら 55 kt 前後）になったら <kbd>S</kbd> で機首を上げる</li><li>地面を離れたら <kbd>G</kbd> でギアを上げ、<kbd>V</kbd> でフラップを 0° に</li><li>ほしい高さまで上昇したら、キーを離して水平に（アシスト ON の場合）</li></ol>
        <h3>着陸の手順</h3>
        <ol><li>滑走路の延長線上に機首を合わせる（方位計の紫の印が目印）</li><li>ギアを下げ、フラップを 20〜30° に</li><li>滑走路左の 4 つの灯火（PAPI）が「赤 2・白 2」になる角度で降りていく。白が多いと高すぎ、赤が多いと低すぎ</li><li>スロットルを少しずつ絞り、地面の直前で機首を軽く上げる（フレア）</li><li>接地したらスロットル 0、<kbd>B</kbd> でブレーキ</li></ol>
        <h3>遠くの空港へ（例：羽田 → 那覇）</h3>
        <ol><li>メニューで出発空港と目的地を選ぶ（または <kbd>M</kbd> の地図で空港をクリック）</li><li>離陸して上昇し、安全な高度（旅客機なら 10,000 ft 以上）で <kbd>O</kbd>（オートパイロット）</li><li><kbd>Z</kbd> で時間を早送り。地図（<kbd>M</kbd>）で現在地を確認</li><li>目的地の 30 km 手前で知らせが出たら <kbd>O</kbd> で解除し、高度を下げて着陸</li></ol>
        <h3>世界の空港へ（例：羽田 → ニューヨーク）</h3>
        <ol><li>メニューの「目的地」から選ぶか、<kbd>M</kbd> の地図の上の検索欄に「ニューヨーク」「JFK」「パリ」などと入力して空港を選び「目的地に設定」</li><li>離陸して旅客機なら 35,000 ft（約 11,000 m）まで上昇し、<kbd>O</kbd>（オートパイロット）。地球の丸みに沿った最短ルート（大圏航路）で飛びます</li><li><kbd>Z</kbd> を何回か押して ×64 に。羽田 → ニューヨークはゲーム内で約 11 時間、×64 なら約 10 分です</li><li>近づいたら <kbd>O</kbd> で解除して降下・着陸</li></ol>
        <p>海外でも、航空写真・地形・建物（OpenStreetMap）・名所（エッフェル塔、自由の女神、シドニー・オペラハウスなど）が表示されます。出発空港を海外にすれば、観光フライトも海外の名所でできます。</p>
        <h3>観光フライト</h3>
        <p>メニューの「観光フライト」を選ぶと、出発空港の近くの名所（東京なら東京タワー・スカイツリー・皇居など）の横にリングが並びます。紫の枠を順番にくぐると、その名所の説明が表示されます。★ の付いた金色の名前が名所です。</p>
        <h3>夜の飛行</h3>
        <p>メニューの「時間帯」で「夜」を選ぶと、街の明かり・ビルの窓の灯り・滑走路の灯火・星空の中を飛べます。滑走路の両側の白い灯火の列、手前の緑（入口）、奥の赤（終わり）を目印に着陸します。翼の先の赤（左）と緑（右）は自分の機体の航法灯です。</p>
        <h3>本物の 3D の街</h3>
        <p>詳細版では、東京 23 区・大阪・名古屋・京都・福岡など全国 300 地域で、国土交通省 PLATEAU の「写真の貼られた 3D 建物」が表示されます（近づくと読み込まれます）。それ以外の地域は OpenStreetMap の建物を実際の高さで表示します。</p>
        <h3>困ったときは</h3>
        <ul><li>「STALL 失速」が出たら：機首を下げ（<kbd>W</kbd>）、スロットルを上げる</li><li>「PULL UP」が出たら：地面や山が近い。機首を上げてスロットル全開</li><li>どうなっているかわからない：<kbd>L</kbd> で水平飛行に戻す</li></ul>
      </section>
      <section data-tab="numbers" hidden>
        <h3>どこを見ればいい？</h3>
        <ul>
          <li><b>ピッチ（機首の上げ下げの角度）</b>：姿勢指示器（青と茶色の丸）で、黄色い機体記号が水平線からどれだけ上にあるか。はしご状の線は 10° ごと、短い線は 5° ごとです。</li>
          <li><b>バンク（左右の傾き）</b>：姿勢指示器の上の弧の目盛り。10°・20°・30°・45°・60° に印があります。上の白い三角が目盛りのどこを指しているかで読みます。</li>
          <li><b>スロットル</b>：計器パネル中央の THR の緑のバー（%）。<kbd>R</kbd> で上げる、<kbd>F</kbd> で下げる。</li>
          <li><b>水平かどうか</b>：昇降計（高度計の右の細い目盛り）が 0、高度計の数字が変わらなければ水平飛行です。</li>
        </ul>
        <p class="note-box">飛行中は、計器パネルの右に<b>「目安」パネル</b>が出ます。いまが水平・上昇・降下のどれか、傾き（バンク）とフラップに合わせて、その状態で安定させるスロットルとピッチを表示します。合っていれば緑、ずれていれば黄色になります。</p>
        <h3>基本のルール</h3>
        <ol>
          <li><b>高さはピッチで、速さはスロットルで</b>調整します。高度が下がってきたら機首を 1° 上げる、速度が落ちてきたらスロットルを 5% 上げる、の繰り返しです。</li>
          <li><b>傾けると（旋回すると）機体は沈みます</b>。翼の力の一部が横向きになるからです。水平を保つには、機首を少し上げ、スロットルも少し足します。必要な量はバンクが深いほど大きくなります。</li>
          <li>旋回中は体にかかる重さ（G）が増えます：15° で 1.04 倍、30° で 1.15 倍、45° で 1.41 倍、60° で 2 倍。<b>失速する速度も上がる</b>ので、低速で深く傾けるのは危険です。低い高度や遅い速度では 30° までにしましょう。</li>
          <li>旋回をやめるときは、傾きを戻すと同時に、足した機首上げとスロットルを元に戻します（戻さないと上昇して速度が落ちます）。</li>
          <li><b>上昇・降下のはじめかた</b>：① ピッチを表の値に合わせる → ② スロットルを表の値に合わせる → ③ 昇降計の数字が目標（例：+500）になるまで待って、ずれていればピッチを 1° ずつ直す。止めるとき（水平に戻すとき）は逆に ① ピッチを水平の値に戻す → ② スロットルを水平の値に戻す。</li>
          <li>上昇・降下しながら曲がるときは、バンク 10〜20° までにしましょう。表の 10° と 20° の値を使います。</li>
        </ol>
        <p><b>操縦アシスト ON</b> のときは、ピッチの調整（沈まないように機首を上げる）は自動でやってくれます。スロットルだけ下の表を目安に合わせてください。<b>アシスト OFF</b> のときは、ピッチもスロットルも自分で合わせます。</p>

// ---------- small math ----------
const DEG = Math.PI / 180;
const clamp = (x, a, b) => x < a ? a : x > b ? b : x;
const lerp = (a, b, t) => a + (b - a) * t;
const smoothstep = (a, b, x) => { const t = clamp((x - a) / (b - a), 0, 1); return t * t * (3 - 2 * t); };
const damp = (a, b, rate, dt) => lerp(a, b, 1 - Math.exp(-rate * dt));

const vadd = (a, b) => [a[0] + b[0], a[1] + b[1], a[2] + b[2]];
const vsub = (a, b) => [a[0] - b[0], a[1] - b[1], a[2] - b[2]];
const vscale = (a, s) => [a[0] * s, a[1] * s, a[2] * s];
const vmadd = (a, b, s) => [a[0] + b[0] * s, a[1] + b[1] * s, a[2] + b[2] * s];
const vdot = (a, b) => a[0] * b[0] + a[1] * b[1] + a[2] * b[2];
const vcross = (a, b) => [a[1] * b[2] - a[2] * b[1], a[2] * b[0] - a[0] * b[2], a[0] * b[1] - a[1] * b[0]];

const vlerp = (a, b, t) => [lerp(a[0], b[0], t), lerp(a[1], b[1], t), lerp(a[2], b[2], t)];
const vdist = (a, b) => Math.hypot(a[0] - b[0], a[1] - b[1], a[2] - b[2]);

const qmul = (a, b) => [
  a[3] * b[0] + a[0] * b[3] + a[1] * b[2] - a[2] * b[1],
  a[3] * b[1] - a[0] * b[2] + a[1] * b[3] + a[2] * b[0],
  a[3] * b[2] + a[0] * b[1] - a[1] * b[0] + a[2] * b[3],
  a[3] * b[3] - a[0] * b[0] - a[1] * b[1] - a[2] * b[2]];

function qrot(q, v) {
  const x = q[0], y = q[1], z = q[2], w = q[3];
  const tx = 2 * (y * v[2] - z * v[1]), ty = 2 * (z * v[0] - x * v[2]), tz = 2 * (x * v[1] - y * v[0]);
  return [v[0] + w * tx + (y * tz - z * ty), v[1] + w * ty + (z * tx - x * tz), v[2] + w * tz + (x * ty - y * tx)];
}
function qslerp(a, b, t) {
  let d = a[0] * b[0] + a[1] * b[1] + a[2] * b[2] + a[3] * b[3];
  if (d < 0) { b = [-b[0], -b[1], -b[2], -b[3]]; d = -d; }
  if (d > 0.9995) return qnorm([lerp(a[0], b[0], t), lerp(a[1], b[1], t), lerp(a[2], b[2], t), lerp(a[3], b[3], t)]);

  return [a[0] * wa + b[0] * wb, a[1] * wa + b[1] * wb, a[2] * wa + b[2] * wb, a[3] * wa + b[3] * wb];
}

function qFromHPB(hdg, pitch = 0, bank = 0) {

}

const M4 = {

    const t = 1 / Math.tan(fovy / 2), m = new Float32Array(16);
    m[0] = t / asp; m[5] = t; m[10] = (f + n) / (n - f); m[11] = -1; m[14] = 2 * f * n / (n - f);
    return m;
  },
  mul(a, b) {
    const o = new Float32Array(16);
    for (let c = 0; c < 4; c++) for (let r = 0; r < 4; r++) {
      o[c * 4 + r] = a[r] * b[c * 4] + a[4 + r] * b[c * 4 + 1] + a[8 + r] * b[c * 4 + 2] + a[12 + r] * b[c * 4 + 3];
    }
    return o;
  },

    m[12] = p[0]; m[13] = p[1]; m[14] = p[2]; m[15] = 1;
    return m;
  },

    return new Float32Array([s[0], u[0], -f[0], 0, s[1], u[1], -f[1], 0, s[2], u[2], -f[2], 0,
      -vdot(s, e), -vdot(u, e), vdot(f, e), 1]);
  },

    const rp = qrot(q, pivot);
    r[12] = pivot[0] - rp[0]; r[13] = pivot[1] - rp[1]; r[14] = pivot[2] - rp[2];
    return r;
  },
  ident() { const m = new Float32Array(16); m[0] = m[5] = m[10] = m[15] = 1; return m; },
};
function frustumPlanes(m) {
  const P = [];
  const row = r => [m[r], m[4 + r], m[8 + r], m[12 + r]];
  const r0 = row(0), r1 = row(1), r2 = row(2), r3 = row(3);
  for (const [a, s] of [[r0, 1], [r0, -1], [r1, 1], [r1, -1], [r2, 1], [r2, -1]]) {
    P.push([r3[0] + s * a[0], r3[1] + s * a[1], r3[2] + s * a[2], r3[3] + s * a[3]]);
  }
  return P;
}
function boxInFrustum(P, x0, y0, z0, x1, y1, z1) {
  for (const p of P) {
    const x = p[0] > 0 ? x1 : x0, y = p[1] > 0 ? y1 : y0, z = p[2] > 0 ? z1 : z0;
    if (p[0] * x + p[1] * y + p[2] * z + p[3] < 0) return false;
  }
  return true;
}

// ---------- random & noise ----------
function makeRng(seed) {
  let s = seed >>> 0;
  return () => {
    s = (s + 0x6D2B79F5) >>> 0; let t = s;
    t = Math.imul(t ^ (t >>> 15), t | 1); t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
function hash2(x, y, s = 0) {
  let h = (Math.imul(x | 0, 374761393) + Math.imul(y | 0, 668265263) + Math.imul(s | 0, 1440662683)) | 0;
  h = Math.imul(h ^ (h >>> 13), 1274126177); h ^= h >>> 16;
  return (h >>> 0) / 4294967296;
}
const PERM = new Uint8Array(512);
(() => {
  const r = makeRng(20240917), p = [...Array(256).keys()];
  for (let i = 255; i > 0; i--) { const j = Math.floor(r() * (i + 1)); [p[i], p[j]] = [p[j], p[i]]; }
  for (let i = 0; i < 512; i++) PERM[i] = p[i & 255];
})();
const GX = new Float32Array(16), GY = new Float32Array(16);
for (let i = 0; i < 16; i++) { GX[i] = Math.cos(i * Math.PI / 8); GY[i] = Math.sin(i * Math.PI / 8); }
function perlinCore(xf, yf, a, b, c, d) {
  const u = xf * xf * xf * (xf * (xf * 6 - 15) + 10), v = yf * yf * yf * (yf * (yf * 6 - 15) + 10);
  const n00 = GX[a] * xf + GY[a] * yf, n10 = GX[b] * (xf - 1) + GY[b] * yf;
  const n01 = GX[c] * xf + GY[c] * (yf - 1), n11 = GX[d] * (xf - 1) + GY[d] * (yf - 1);
  const x0 = n00 + u * (n10 - n00), x1 = n01 + u * (n11 - n01);
  return (x0 + v * (x1 - x0)) * 1.42;
}
function perlin(x, y) {
  const xi = Math.floor(x), yi = Math.floor(y), X = xi & 255, Y = yi & 255;
  return perlinCore(x - xi, y - yi, PERM[X + PERM[Y]] & 15, PERM[X + 1 + PERM[Y]] & 15,
    PERM[X + PERM[Y + 1]] & 15, PERM[X + 1 + PERM[Y + 1]] & 15);
}
function perlinP(x, y, per) { // tileable with period `per`
  const xi = Math.floor(x), yi = Math.floor(y);
  const X0 = ((xi % per) + per) % per, Y0 = ((yi % per) + per) % per, X1 = (X0 + 1) % per, Y1 = (Y0 + 1) % per;
  return perlinCore(x - xi, y - yi, PERM[X0 + PERM[Y0]] & 15, PERM[X1 + PERM[Y0]] & 15,
    PERM[X0 + PERM[Y1]] & 15, PERM[X1 + PERM[Y1]] & 15);
}
function fbm(x, y, oct) {
  let s = 0, a = 1, n = 0;
  for (let i = 0; i < oct; i++) { s += a * perlin(x, y); n += a; a *= 0.5; x = x * 2.02 + 17.3; y = y * 2.02 - 9.1; }
  return s / n;
}
function ridged(x, y, oct) {
  let s = 0, a = 0.5, w = 1, n = 0;
  for (let i = 0; i < oct; i++) {
    let r = 1 - Math.abs(perlin(x, y)); r *= r; r *= w; w = clamp(r * 2, 0, 1);
    s += r * a; n += a; a *= 0.5; x = x * 2.03 + 5.1; y = y * 2.03 - 3.7;
  }
  return s / n;
}

function compileShader(type, src) {
  const s = gl.createShader(type);
  gl.shaderSource(s, src); gl.compileShader(s);
  if (!gl.getShaderParameter(s, gl.COMPILE_STATUS)) {
    const log = gl.getShaderInfoLog(s);
    console.error(log + '\n' + src.split('\n').map((l, i) => (i + 1) + ': ' + l).join('\n'));
    throw new Error('Shader compile failed: ' + log);
  }
  return s;
}
function makeProgram(vs, fs) {
  const p = gl.createProgram();
  gl.attachShader(p, compileShader(gl.VERTEX_SHADER, vs));
  gl.attachShader(p, compileShader(gl.FRAGMENT_SHADER, fs));
  gl.linkProgram(p);
  if (!gl.getProgramParameter(p, gl.LINK_STATUS)) throw new Error('Link failed: ' + gl.getProgramInfoLog(p));
  const u = {};
  const n = gl.getProgramParameter(p, gl.ACTIVE_UNIFORMS);
  for (let i = 0; i < n; i++) {
    const info = gl.getActiveUniform(p, i);
    u[info.name.replace(/\[0\]$/, '')] = gl.getUniformLocation(p, info.name);
  }
  if (u.uSunShadow) { gl.useProgram(p); gl.uniform1i(u.uSunShadow, 11); }      // its own unit (a shadow sampler can't share one)
  if (u.uNP) { gl.useProgram(p); gl.uniform1i(u.uNP, 13); }                      // the aerial photo round the car
  if (u.uMat) { gl.useProgram(p); gl.uniform1i(u.uMat, 14); }                    // the city's photo materials
  if (u.uMatN) { gl.useProgram(p); gl.uniform1i(u.uMatN, 16); }                  // ...their relief and gloss
  if (u.uTranMask) { gl.useProgram(p); gl.uniform1i(u.uTranMask, 17); }          // where PLATEAU's roads stand in for the sim's
  if (u.uCards) { gl.useProgram(p); gl.uniform1i(u.uCards, 15); }                // the photo tree cards
  return { p, u };
}
// vertex buffers: attribs = [{loc, size, data, divisor?, dynamic?}] ; interleaved = {loc: [size, offset]}
function makeVAO(attribs, indices) {
  const vao = gl.createVertexArray();
  gl.bindVertexArray(vao);
  const bufs = [];
  for (const a of attribs) {
    const b = gl.createBuffer();
    gl.bindBuffer(gl.ARRAY_BUFFER, b);
    gl.bufferData(gl.ARRAY_BUFFER, a.data, a.dynamic ? gl.DYNAMIC_DRAW : gl.STATIC_DRAW);
    if (a.layout) { // interleaved
      const stride = a.stride * 4;
      for (const [loc, size, off] of a.layout) {
        gl.enableVertexAttribArray(loc);
        gl.vertexAttribPointer(loc, size, gl.FLOAT, false, stride, off * 4);
        if (a.divisor) gl.vertexAttribDivisor(loc, a.divisor);
      }
    } else {
      gl.enableVertexAttribArray(a.loc);
      gl.vertexAttribPointer(a.loc, a.size, gl.FLOAT, false, 0, 0);
      if (a.divisor) gl.vertexAttribDivisor(a.loc, a.divisor);
    }
    bufs.push(b);
  }
  let ib = null;
  if (indices) {
    ib = gl.createBuffer();
    gl.bindBuffer(gl.ELEMENT_ARRAY_BUFFER, ib);
    gl.bufferData(gl.ELEMENT_ARRAY_BUFFER, indices, gl.STATIC_DRAW);
  }
  gl.bindVertexArray(null);
  return { vao, bufs, ib, count: indices ? indices.length : 0 };
}
function makeTexture(opts) {
  const t = gl.createTexture();
  gl.bindTexture(gl.TEXTURE_2D, t);
  gl.pixelStorei(gl.UNPACK_ALIGNMENT, 1);
  if (opts.source) gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, gl.RGBA, gl.UNSIGNED_BYTE, opts.source);
  else gl.texImage2D(gl.TEXTURE_2D, 0, opts.internal, opts.w, opts.h, 0, opts.format, opts.type, opts.data);
  const wrap = opts.wrap || gl.CLAMP_TO_EDGE;
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_S, wrap);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_T, wrap);
  if (opts.nearest) {
    gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.NEAREST);
    gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, gl.NEAREST);
  } else {
    gl.generateMipmap(gl.TEXTURE_2D);
    gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.LINEAR_MIPMAP_LINEAR);
    gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, gl.LINEAR);
    if (anisoExt && opts.aniso) {
      gl.texParameterf(gl.TEXTURE_2D, anisoExt.TEXTURE_MAX_ANISOTROPY_EXT,
        Math.min(opts.aniso, gl.getParameter(anisoExt.MAX_TEXTURE_MAX_ANISOTROPY_EXT)));
    }
  }
  return t;
}

  float m = airMass(uSunDir.y);

vec3 atmoSky(vec3 d){
  float h0 = max(uCamPos.y, 0.0);
  // ray length: to the top of the atmosphere, or to the ground below the horizon
  // on a curved Earth (R = 6371 km): a slightly downward ray may still miss the ground and leave the atmosphere
  const float RE = 6.371e6, HTOP = 6.0e4;
  float disc = d.y * d.y - 2.0 * h0 / RE;
  float tMax = (d.y < 0.0 && disc > 0.0) ? RE * (-d.y - sqrt(disc)) : RE * (-d.y + sqrt(d.y * d.y + 2.0 * (HTOP - h0) / RE));
  tMax = min(tMax, 4.0e5);
  const int N = 12;
  float mu = dot(d, uSunDir), odR = 0.0, odM = 0.0;
  vec3 sR = vec3(0.0), sM = vec3(0.0);
  float tPrev = 0.0;
  for (int i = 1; i <= N; i++) {
    float f = float(i) / float(N), t = tMax * f * f, ds = t - tPrev; tPrev = t;
    float h = max(h0 + d.y * (t - ds * 0.5) + (t * t) / (2.0 * 6.371e6), 0.0);
    float r = exp(-h / HR) * ds, m = exp(-h / HM) * ds;
    odR += r; odM += m;
    vec3 att = exp(-(BR * odR + BMS * 1.1 * uHaze * odM)) * sunTrans(h);
    sR += r * att; sM += m * att;
  }
  vec3 L = uSunI * (BR * phaseR(mu) * sR + BMS * uHaze * phaseM(mu) * sM);
  // multiple scattering / skylight fill so the shadowed side of the sky is not black
  L += uSunI * 0.012 * BR * 2.0e4 * (0.35 + 0.65 * max(uSunDir.y + 0.1, 0.0)) * exp(-h0 / 9000.0) * (1.0 - exp(-(odR * 1.5e-5)));
  // multiple scattering whitens the low sky: pull toward the luminance near the horizon
  float lum = dot(L, vec3(0.2126, 0.7152, 0.0722));
  L = mix(L, vec3(lum) * vec3(0.96, 1.0, 1.08), 0.35 * exp(-abs(d.y) * 7.0) * smoothstep(-0.05, 0.25, uSunDir.y));
  return L;
}
vec3 skyColor(vec3 d){
  if (uSunI > 0.0) {
    vec3 c = atmoSky(d);
    if (d.y < 0.0) c = mix(c, c * 0.8 + uAmbGround * 0.15, smoothstep(0.0, -0.25, d.y));
    return c;
  }
  float y = d.y;
  vec2 hz = normalize(d.xz + vec2(1e-5));
  vec2 sz = normalize(uSunDir.xz + vec2(1e-5));
  float towards = dot(hz, sz) * 0.5 + 0.5;
  vec3 hor = mix(uHorizonAway, uHorizon, towards * towards);

  c = mix(c, hor * 0.82, smoothstep(0.0, -0.3, y));

  c += uSunCol * (pow(sd, 5.0) * 0.10 + pow(sd, 60.0) * 0.30);
  return c;
}

// what a glossy surface mirrors in a street (uUrban 1): the sky above the roofline, the buildings across the
// street (a wall each ten degrees round, its rows of windows mirroring the sky behind you), the road below;

  vec3 c = skyEnv(normalize(vec3(R.x, max(R.y, 0.0), R.z)));
  if (uUrban > 0.0) {
    float az = atan(R.z, R.x) * 3.58, k = floor(az), hb = fract(sin(k * 12.9898) * 43758.5453);   // (a building every 16 degrees round)
    float roof = (0.05 + 0.2 * hb) * uUrban, fw = max(fwidth(R.y), 0.004);
    float inB = 1.0 - smoothstep(roof - fw, roof + fw, R.y);
    if (inB > 0.0) {
      vec3 Rh = normalize(vec3(-R.x, 0.0, -R.z));
      vec3 wall = mix(vec3(0.55, 0.54, 0.52), vec3(0.8, 0.78, 0.74), fract(hb * 7.31));
      wall *= skyIrr(Rh) * 1.1 + uSunCol * (max(dot(Rh, uSunDir), 0.0) * 0.8 + 0.12);   // (walls in the sun, or lit by the street and the sky)
      float fr = (16.0 + 14.0 * fract(hb * 3.7)) * R.y, rw = fwidth(fr) + 0.05;
      float row = smoothstep(0.4 - rw, 0.4 + rw, fract(fr)) * (1.0 - smoothstep(0.9 - rw, 0.9 + rw, fract(fr)));
      c = mix(c, mix(wall, skyEnv(normalize(vec3(-R.x, 0.35, -R.z))) * 0.6, row * 0.28), inB);
    }
  }
  if (R.y < 0.0) c = mix(c, vec3(0.19, 0.19, 0.2) * (uSunCol * max(uSunDir.y, 0.0) * 0.9 + uAmbSky), smoothstep(0.0, -0.05, R.y));
  return mix(c, skyIrr(R) * 0.9, smoothstep(0.08, 0.5, rough));      // (a rough surface: only the blurred light of it all)
}
float fresnelS(float NV, float f0){ return f0 + (1.0 - f0) * pow(1.0 - NV, 5.0); }
// optical depth of an exponential layer (scale height H) along a straight segment
float odExp(float h0, float dy, float L, float H){
  float e0 = exp(-max(h0, -200.0) / H);
  return abs(dy * L) > 1e-3 ? e0 * H * (1.0 - exp(-dy * L / H)) / dy : e0 * L;
}
vec3 applyFog(vec3 col, vec3 p){
  vec3 dv = p - uCamPos;
  float dist = length(dv);
  vec3 dir = dv / max(dist, 1e-3);
  if (uSunI > 0.0) {
    // aerial perspective: extinction plus in-scattered sun and sky light along the view segment
    float h0 = uCamPos.y, odR = odExp(h0, dir.y, dist, HR), odM = odExp(h0, dir.y, dist, HM) * uHaze;
    vec3 ext = BR * odR + BMS * 1.1 * odM, T = exp(-ext);
    float mu = dot(dir, uSunDir);
    vec3 sc = BR * phaseR(mu) * odR + BMS * phaseM(mu) * odM;
    vec3 sun = uSunI * sunTrans(max(min(h0, p.y) + 0.5 * abs(p.y - h0), 0.0));
    vec3 ins = sun * sc / max(ext, vec3(1e-9)) * (1.0 - T);
    vec3 hz = atmoSky(normalize(vec3(dir.x, max(dir.y, 0.02), dir.z)));
    ins += hz * (1.0 - T) * 0.55;                                     // skylight scattered into the view ray
    // far away the view ray ends in haze: converge on the sky colour of that direction so ground meets sky seamlessly
    return mix(col * T + ins * 0.62, skyColor(dir), smoothstep(0.55, 0.97, 1.0 - T.g) * 0.95);
  }
  const float b = 0.00042;
  float cy = max(uCamPos.y, 0.0);
  float dy = dir.y;
  float fog = abs(dy) > 1e-4
    ? uFogDens * exp(-cy * b) * (1.0 - exp(-dist * dy * b)) / (dy * b)
    : uFogDens * exp(-cy * b) * dist;
  fog = 1.0 - exp(-max(fog, 0.0));
  return mix(col, skyColor(dir), clamp(fog, 0.0, 1.0));
}

vec3 tonemap(vec3 c){
  // a film's shoulder for the highlights, then the grade of a sunny open-world game: a little more colour,
  // a gentle S-curve for contrast, sunlit tones a shade warm and the shade a shade cool
  c = max(c, 0.0);

// ---------- procedural textures ----------
function makeNoiseTexture() {
  const S = 256, data = new Uint8Array(S * S * 4);
  const hA = new Float32Array(S * S);
  const f = (u, v, base, oct, off) => {
    let s = 0, a = 0.5;
    for (let o = 0; o < oct; o++) { const p = base << o; s += a * perlinP(u * p + off, v * p + off, p); a *= 0.5; }
    return s;
  };
  for (let y = 0; y < S; y++) for (let x = 0; x < S; x++) hA[y * S + x] = f(x / S, y / S, 8, 5, 0);
  for (let y = 0; y < S; y++) for (let x = 0; x < S; x++) {
    const i = (y * S + x) * 4;
    const dx = hA[y * S + ((x + 1) % S)] - hA[y * S + ((x + S - 1) % S)];
    const dy = hA[((y + 1) % S) * S + x] - hA[((y + S - 1) % S) * S + x];
    data[i] = clamp(128 - dx * 900, 0, 255);
    data[i + 1] = clamp(128 - dy * 900, 0, 255);
    data[i + 2] = clamp(128 + f(x / S, y / S, 16, 4, 64) * 330, 0, 255);
    data[i + 3] = clamp(128 + f(x / S, y / S, 4, 4, 128) * 300, 0, 255);
  }
  return makeTexture({ internal: gl.RGBA8, format: gl.RGBA, type: gl.UNSIGNED_BYTE, w: S, h: S, data, wrap: gl.REPEAT, aniso: 8 });
}
function makePuffTexture() {
  const S = 128, data = new Uint8Array(S * S);
  for (let y = 0; y < S; y++) for (let x = 0; x < S; x++) {
    const dx = (x + 0.5) / S * 2 - 1, dy = (y + 0.5) / S * 2 - 1, r = Math.hypot(dx, dy);
    const base = smoothstep(1.0, 0.2, r);
    const n = fbm(dx * 2.6 + 5.3, dy * 2.6 + 1.7, 4) * 0.5 + 0.5;
    data[y * S + x] = clamp((base * (0.45 + 0.95 * n) - 0.12 * (1 - base)) * 255, 0, 255);
  }
  return makeTexture({ internal: gl.R8, format: gl.RED, type: gl.UNSIGNED_BYTE, w: S, h: S, data });
}
function makeDotTexture() {
  const S = 64, data = new Uint8Array(S * S);
  for (let y = 0; y < S; y++) for (let x = 0; x < S; x++) {
    const r = Math.hypot((x + 0.5) / S * 2 - 1, (y + 0.5) / S * 2 - 1);
    data[y * S + x] = clamp((1 - smoothstep(0.0, 1.0, r)) * 255 * 1.2, 0, 255);
  }
  return makeTexture({ internal: gl.R8, format: gl.RED, type: gl.UNSIGNED_BYTE, w: S, h: S, data });
}

function hTexel(i, j) {
  i = i < 0 ? 0 : i >= HM_N ? HM_N - 1 : i;
  j = j < 0 ? 0 : j >= HM_N ? HM_N - 1 : j;
  return heights[j * HM_N + i];

function terrainHeight(x, z) {
  const fx = (x + HM_HALF) / HM_CELL, fz = (z + HM_HALF) / HM_CELL;
  const ix = Math.floor(fx), iz = Math.floor(fz), tx = fx - ix, tz = fz - iz;
  const a = hTexel(ix, iz), b = hTexel(ix + 1, iz), c = hTexel(ix, iz + 1), d = hTexel(ix + 1, iz + 1);
  return lerp(lerp(a, b, tx), lerp(c, d, tx), tz);
}
function terrainNormal(x, z) {
  const e = HM_CELL;
  return vnorm([terrainHeight(x - e, z) - terrainHeight(x + e, z), 2 * e, terrainHeight(x, z - e) - terrainHeight(x, z + e)]);
}
function vegAt(x, z) {
  const i = clamp(Math.round((x + HM_HALF) / HM_CELL), 0, HM_N - 1), j = clamp(Math.round((z + HM_HALF) / HM_CELL), 0, HM_N - 1);
  return vegData[j * HM_N + i];
}
function onPaved(x, z) {
  const [u, v0] = worldToRwy(x, z);
  if (Math.abs(u) <= RWY.len / 2 && Math.abs(v0) <= RWY.wid / 2) return 'rwy';
  const v = v0 * (RWY.side || 1);
  if (u >= APRON.u0 && u <= APRON.u1 && v >= APRON.v0 && v <= APRON.v1) return 'apron';
  if (u >= -300 && u <= -270 && v >= -45 && v <= -RWY.wid / 2) return 'apron';
  if (u >= -20 && u <= 10 && v >= -45 && v <= -RWY.wid / 2) return 'apron';
  return null;
}
// ground used by the physics: water counts as a (deadly) surface at y = 0
function groundAt(x, z) {
  const h = terrainHeight(x, z);
  const paved = onPaved(x, z);
  if (paved) return { h: RWY.elev + (paved === 'rwy' ? 0.12 : 0.08), n: [0, 1, 0], paved: true, water: false };
  if (h < 0) return { h: 0, n: [0, 1, 0], paved: false, water: true };
  return { h, n: terrainNormal(x, z), paved: false, water: false };
}

function terrainNatural(x, z) {
  const nx = x / HM_HALF, nz = z / HM_HALF;
  const wx = fbm(nx * 1.6 + 3.1, nz * 1.6 - 7.4, 3) * 0.16, wz = fbm(nx * 1.6 - 2.3, nz * 1.6 + 5.5, 3) * 0.16;
  const px = nx + wx, pz = nz + wz;
  const r = Math.hypot(px, pz * 1.1);
  const land = 1 - smoothstep(0.40, 0.80, r + fbm(nx * 4.3 + 1.7, nz * 4.3 + 9.2, 4) * 0.12);
  let h = (land - 0.52) * 170;
  h += fbm(px * 7 + 4.4, pz * 7 - 1.3, 5) * 60 * land;
  const mx = px - 0.04, mz = pz + 0.16;
  const md = Math.hypot(mx * 1.15, mz) + fbm(px * 3.1 - 6, pz * 3.1 + 2, 3) * 0.18;
  const mMask = (1 - smoothstep(0.04, 0.52, md)) * land;
  const rg = ridged(px * 3.6 + 11.7, pz * 3.6 + 3.3, 6);
  h += mMask * (150 + Math.pow(rg, 1.7) * 1500);
  return Math.max(h, -95);
}

async function decodeRealTerrain(id) {
  const N = HM_N, b64 = MAP_DATA[id].data;
  const bin = Uint8Array.from(atob(b64), c => c.charCodeAt(0));
  const stream = new Blob([bin]).stream().pipeThrough(new DecompressionStream('deflate'));
  const d = new Int16Array(await new Response(stream).arrayBuffer());
  const sea = new Uint8Array(N * N);
  for (let j = 0; j < N; j++) {
    let acc = 0;
    for (let i = 0; i < N; i++) {
      const k = j * N + i;
      acc = ((acc + d[k]) << 16) >> 16;
      if (acc === -32768) { sea[k] = 1; heights[k] = 0; } else heights[k] = acc / 10;
    }
  }
  // land touching the edge of the data slopes down into the sea
  const margin = 48;
  for (let j = 0; j < N; j++) for (let i = 0; i < N; i++) {
    const k = j * N + i; if (sea[k]) continue;
    const e = Math.min(i, j, N - 1 - i, N - 1 - j);
    if (e >= margin) continue;
    const t = smoothstep(0, margin, e + perlin(i * 0.05, j * 0.05) * 14);
    heights[k] = heights[k] * t - 12 * (1 - t);
    if (heights[k] < 0) sea[k] = 1;
  }
  // sea depth grows with distance from the shore (the elevation data has no bathymetry)
  const dist = new Float32Array(N * N);
  for (let k = 0; k < N * N; k++) dist[k] = sea[k] ? 1e9 : 0;
  const R2 = Math.SQRT2;
  for (let j = 0; j < N; j++) for (let i = 0; i < N; i++) {
    const k = j * N + i; if (!sea[k]) continue;
    let v = dist[k];
    if (i > 0) v = Math.min(v, dist[k - 1] + 1);
    if (j > 0) { v = Math.min(v, dist[k - N] + 1); if (i > 0) v = Math.min(v, dist[k - N - 1] + R2); if (i < N - 1) v = Math.min(v, dist[k - N + 1] + R2); }
    dist[k] = v;
  }
  for (let j = N - 1; j >= 0; j--) for (let i = N - 1; i >= 0; i--) {
    const k = j * N + i; if (!sea[k]) continue;
    let v = dist[k];
    if (i < N - 1) v = Math.min(v, dist[k + 1] + 1);
    if (j < N - 1) { v = Math.min(v, dist[k + N] + 1); if (i < N - 1) v = Math.min(v, dist[k + N + 1] + R2); if (i > 0) v = Math.min(v, dist[k + N - 1] + R2); }
    dist[k] = v;
  }
  for (let k = 0; k < N * N; k++) if (sea[k]) heights[k] = -Math.min(1.2 + Math.min(dist[k], 4000) * HM_CELL * 0.022, 90);
}

// pick the runway end whose 3° approach is clear of terrain, and the side with room for the terminal
function chooseRunwayLayout() {
  const clear = sign => {
    let mn = 1e9;
    for (let d = 200; d <= 6000; d += 100) {
      const p = rwyToWorld(sign > 0 ? -RWY.len / 2 - d : RWY.len / 2 + d, 0);
      mn = Math.min(mn, RWY.elev + Math.tan(3 * DEG) * d - Math.max(terrainHeight(p[0], p[2]), 0));
    }
    return mn;
  };
  if (clear(1) < 60 && clear(-1) > clear(1)) {
    setRunway({ hdg: (RWY.hdg + 180) % 360, idents: [RWY.idents[1], RWY.idents[0]] });
  }
  let best = -1e9;
  for (const side of [-1, 1]) {
    let sc = 0;
    for (let u = -330; u <= 20; u += 35) for (let v = 50; v <= 200; v += 30) {
      const p = rwyToWorld(u, -v * side), h = terrainHeight(p[0], p[2]);
      sc += (h > 0 ? 1 : -1.5) - Math.min(Math.abs(h - RWY.elev) / 20, 2);
    }
    if (sc > best) { best = sc; RWY.side = side; }
  }
}
function flattenAirport(blend) {
  const N = HM_N, reach = RWY.len / 2 + blend + 600;
  const i0 = Math.floor((RWY.cx - reach + HM_HALF) / HM_CELL), i1 = Math.ceil((RWY.cx + reach + HM_HALF) / HM_CELL);
  const j0 = Math.floor((RWY.cz - reach + HM_HALF) / HM_CELL), j1 = Math.ceil((RWY.cz + reach + HM_HALF) / HM_CELL);
  for (let j = Math.max(0, j0); j <= Math.min(N - 1, j1); j++) for (let i = Math.max(0, i0); i <= Math.min(N - 1, i1); i++) {
    const x = -HM_HALF + i * HM_CELL, z = -HM_HALF + j * HM_CELL;
    const [u, v0] = worldToRwy(x, z), v = v0 * (RWY.side || 1);
    const du = Math.max(Math.abs(u) - (RWY.len / 2 + 160), 0), dv = Math.max(v - 70, -210 - v, 0);
    const t = smoothstep(0, blend, Math.hypot(du, dv));
    const k = j * N + i;
    heights[k] = lerp(RWY.elev, heights[k], t);
  }
}

const tick = () => new Promise(r => setTimeout(r, 0));
async function generateWorld(map, onProgress) {
  const N = HM_N;
  MAP = map;
  HM_CELL = map.cell || 20; HM_HALF = N * HM_CELL / 2;
  LEAF = 16 * HM_CELL;
  LOD_RANGE = LOD_BASE.map(r => r * HM_CELL / 20);
  if (map.procedural) {
    setRunway({ cx: -900, cz: 3900, hdg: 90, len: 1400, wid: 30, elev: 20, idents: ['09', '27'], side: 1 });
    for (let j = 0; j < N; j++) {
      const z = -HM_HALF + j * HM_CELL;
      for (let i = 0; i < N; i++) heights[j * N + i] = terrainNatural(-HM_HALF + i * HM_CELL, z);
      if ((j & 15) === 15) { onProgress(0.05 + 0.75 * j / N); await tick(); }
    }
    let sum = 0, cnt = 0;
    for (let u = -RWY.len / 2; u <= RWY.len / 2; u += 50) for (let v = -80; v <= 40; v += 20) {
      const p = rwyToWorld(u, v); sum += terrainHeight(p[0], p[2]); cnt++;
    }
    RWY.elev = Math.max(8, Math.round(sum / cnt));
    flattenAirport(520);
  } else {
    onProgress(0.2); await tick();
    await decodeRealTerrain(map.id);
    onProgress(0.6); await tick();
    setRunway({ cx: (map.le[0] + map.he[0]) / 2, cz: (map.le[1] + map.he[1]) / 2, hdg: map.hdg, len: map.len,
      wid: Math.max(30, map.wid), elev: map.elev, idents: map.idents.slice(), side: 1 });
    let sum = 0, cnt = 0;
    for (let u = -RWY.len / 2; u <= RWY.len / 2; u += 25) { const p = rwyToWorld(u, 0); sum += terrainHeight(p[0], p[2]); cnt++; }
    RWY.elev = Math.max(1.5, Math.round(sum / cnt * 10) / 10);
    chooseRunwayLayout();
    flattenAirport(260);
  }
  onProgress(0.84); await tick();
  // vegetation density
  const urban = URBAN[map.id];
  for (let j = 0; j < N; j++) for (let i = 0; i < N; i++) {
    const x = -HM_HALF + i * HM_CELL, z = -HM_HALF + j * HM_CELL, h = heights[j * N + i];
    let v = clamp(fbm(x / 1500 + 31, z / 1500 - 12, 4) * 0.95 + 0.5, 0, 1);
    v *= 1 - smoothstep(650, 1000, h);
    if (urban) v *= smoothstep(25, 110, h);
    const [u, w0] = worldToRwy(x, z), w = w0 * (RWY.side || 1);
    if (Math.abs(u) < RWY.len / 2 + 250 && w > -260 && w < 120) v *= 0.1;
    vegData[j * N + i] = v;
  }
  onProgress(0.9); await tick();
  buildMinMax();
}

// ---------- GPU resources for terrain ----------
let heightTex, normalTex, noiseTex, puffTex, dotTex;
function uploadWorldTextures() {
  const N = HM_N;
  if (heightTex) { gl.deleteTexture(heightTex); gl.deleteTexture(normalTex); }
  heightTex = makeTexture({ internal: gl.R32F, format: gl.RED, type: gl.FLOAT, w: N, h: N, data: heights, nearest: true });
  const nd = new Uint8Array(N * N * 4);
  for (let j = 0; j < N; j++) for (let i = 0; i < N; i++) {
    const dx = hTexel(i - 1, j) - hTexel(i + 1, j), dz = hTexel(i, j - 1) - hTexel(i, j + 1);
    const n = vnorm([dx, 2 * HM_CELL, dz]), k = (j * N + i) * 4;
    nd[k] = (n[0] * 0.5 + 0.5) * 255; nd[k + 1] = (n[1] * 0.5 + 0.5) * 255; nd[k + 2] = (n[2] * 0.5 + 0.5) * 255;
    nd[k + 3] = vegData[j * N + i] * 255;
  }
  normalTex = makeTexture({ internal: gl.RGBA8, format: gl.RGBA, type: gl.UNSIGNED_BYTE, w: N, h: N, data: nd, aniso: 8 });
  if (!noiseTex) { noiseTex = makeNoiseTexture(); puffTex = makePuffTexture(); dotTex = makeDotTexture(); }
}

// ---------- CDLOD terrain ----------
let LEAF = 320;                                   // 16 heightmap cells
const LOD_TOP = 6;                               // 64 leaves across -> 7 levels
const LOD_BASE = [700, 1400, 2800, 5600, 11200, 22400, 44800];
let LOD_RANGE = LOD_BASE.slice();
const minmax = [];
function buildMinMax() {
  const leafCells = LEAF / HM_CELL, n0 = HM_N * HM_CELL / LEAF;
  let prev = new Float32Array(n0 * n0 * 2);
  for (let j = 0; j < n0; j++) for (let i = 0; i < n0; i++) {
    let mn = 1e9, mx = -1e9;
    for (let y = j * leafCells; y <= (j + 1) * leafCells; y++) for (let x = i * leafCells; x <= (i + 1) * leafCells; x++) {
      const h = hTexel(x, y); if (h < mn) mn = h; if (h > mx) mx = h;
    }
    prev[(j * n0 + i) * 2] = mn; prev[(j * n0 + i) * 2 + 1] = mx;
  }
  minmax[0] = prev;
  for (let L = 1, n = n0 / 2; L <= LOD_TOP; L++, n /= 2) {
    const cur = new Float32Array(n * n * 2), pn = n * 2;
    for (let j = 0; j < n; j++) for (let i = 0; i < n; i++) {
      let mn = 1e9, mx = -1e9;
      for (let c = 0; c < 4; c++) {
        const k = ((j * 2 + (c >> 1)) * pn + i * 2 + (c & 1)) * 2;
        mn = Math.min(mn, prev[k]); mx = Math.max(mx, prev[k + 1]);
      }
      cur[(j * n + i) * 2] = mn; cur[(j * n + i) * 2 + 1] = mx;
    }
    minmax[L] = cur; prev = cur;
  }
}
function boxDist2(p, x0, y0, z0, x1, y1, z1) {
  const dx = Math.max(x0 - p[0], 0, p[0] - x1), dy = Math.max(y0 - p[1], 0, p[1] - y1), dz = Math.max(z0 - p[2], 0, p[2] - z1);
  return dx * dx + dy * dy + dz * dz;
}
function selectTerrain(cam, planes) {
  const out = [];
  const rec = (L, i, j) => {
    const size = LEAF << L, x0 = -HM_HALF + i * size, z0 = -HM_HALF + j * size;
    const n = (HM_N * HM_CELL / LEAF) >> L, k = (j * n + i) * 2;
    const mn = minmax[L][k] - 1, mx = minmax[L][k + 1] + 1;
    if (!boxInFrustum(planes, x0, mn, z0, x0 + size, mx, z0 + size)) return;
    if (L === 0) { out.push([x0, z0, size, 0, 32]); return; }
    const r = LOD_RANGE[L - 1];
    if (boxDist2(cam, x0, mn, z0, x0 + size, mx, z0 + size) > r * r) { out.push([x0, z0, size, L, 32]); return; }
    const h = size / 2, cn = n * 2;
    for (let c = 0; c < 4; c++) {
      const ci = i * 2 + (c & 1), cj = j * 2 + (c >> 1), cx = -HM_HALF + ci * h, cz = -HM_HALF + cj * h;
      const ck = (cj * cn + ci) * 2, cmn = minmax[L - 1][ck] - 1, cmx = minmax[L - 1][ck + 1] + 1;
      if (boxDist2(cam, cx, cmn, cz, cx + h, cmx, cz + h) <= r * r) rec(L - 1, ci, cj);
      else if (boxInFrustum(planes, cx, cmn, cz, cx + h, cmx, cz + h)) out.push([cx, cz, h, L, 16]);
    }
  };
  rec(LOD_TOP, 0, 0);
  return out;
}
function makeGrid(G) {
  const v = new Float32Array((G + 1) * (G + 1) * 2);
  for (let j = 0; j <= G; j++) for (let i = 0; i <= G; i++) { v[(j * (G + 1) + i) * 2] = i; v[(j * (G + 1) + i) * 2 + 1] = j; }
  const idx = new Uint16Array(G * G * 6); let k = 0;
  for (let j = 0; j < G; j++) for (let i = 0; i < G; i++) {
    const a = j * (G + 1) + i, b = a + 1, c = a + G + 1, d = c + 1;
    idx[k++] = a; idx[k++] = c; idx[k++] = b; idx[k++] = b; idx[k++] = c; idx[k++] = d;
  }
  return makeVAO([{ loc: 0, size: 2, data: v }], idx);
}

const GLSL_TERRAIN_H = `

float terrainH(vec2 p){
  vec2 t = (p + uHM.x) / uHM.y; vec2 i = floor(t); vec2 f = t - i; ivec2 c = ivec2(i);
  float a = hTexel(c), b = hTexel(c + ivec2(1, 0)), d = hTexel(c + ivec2(0, 1)), e = hTexel(c + ivec2(1, 1));
  return mix(mix(a, b, f.x), mix(d, e, f.x), f.y);
}
`;

const GLSL_SHADOW = `
uniform vec4 uShadowA;   // shadow centre x,z ; plane forward x,z
uniform vec2 uShadowB;   // strength, softness
float planeShadow(vec2 p){
  if (uShadowB.x <= 0.0) return 1.0;
  vec2 d = p - uShadowA.xy;
  vec2 f = uShadowA.zw, r = vec2(-f.y, f.x);
  float a = dot(d, f), b = dot(d, r);
  float s = uShadowB.y;
  float fus = smoothstep(1.0 + s, 1.0 - s * 0.5, length(vec2(a / 3.8, b / 0.55)));
  float wing = smoothstep(1.0 + s, 1.0 - s * 0.5, length(vec2((a + 0.1) / 0.75, b / 4.8)));
  float tail = smoothstep(1.0 + s, 1.0 - s * 0.5, length(vec2((a + 3.4) / 0.4, b / 1.7)));
  return 1.0 - max(fus, max(wing, tail)) * uShadowB.x;
}
// the sharp aerial photo round the car (p_nearphoto.js): its colour, and how much it applies (0 outside)
uniform sampler2D uNP;
uniform vec4 uNPRect;    // world x, z of its north-west corner, its width and depth
uniform vec4 uNPFade;    // the car's x, z; full within, none beyond
vec4 nearPhoto(vec3 w){
  if (uNPRect.z <= 0.0) return vec4(0.0);
  vec2 uv = (w.xz - uNPRect.xy) / uNPRect.zw;
  if (uv.x < 0.0 || uv.y < 0.0 || uv.x > 1.0 || uv.y > 1.0) return vec4(0.0);
  vec2 e = min(uv, 1.0 - uv);
  float k = (1.0 - smoothstep(uNPFade.z, uNPFade.w, length(w.xz - uNPFade.xy))) * smoothstep(0.0, 0.03, min(e.x, e.y));
  vec4 t = texture(uNP, uv);                                        // (alpha 0 where a tile hasn't come)
  return vec4(t.rgb / max(t.a, 0.01), k * smoothstep(0.5, 0.95, t.a));
}
// the painted markings in that photo, as a crisp mask (lines, crossings, arrows: paint brighter than the
// road round it), and the road's own colour smoothed over a couple of metres
vec4 nearPaint(vec3 w){
  if (uNPRect.z <= 0.0) return vec4(0.0);
  vec2 uv = (w.xz - uNPRect.xy) / uNPRect.zw;
  if (uv.x < 0.0 || uv.y < 0.0 || uv.x > 1.0 || uv.y > 1.0) return vec4(0.0);
  vec4 t = texture(uNP, uv), b = texture(uNP, uv, 3.0);
  if (t.a < 0.9 || b.a < 0.9) return vec4(0.0);
  float l = dot(t.rgb, vec3(0.3, 0.55, 0.15)), lb = dot(b.rgb, vec3(0.3, 0.55, 0.15));
  float sat = max(t.r, max(t.g, t.b)) - min(t.r, min(t.g, t.b));
  float white = smoothstep(0.07, 0.15, l - lb) * (1.0 - smoothstep(0.12, 0.22, sat));
  float yellow = smoothstep(0.05, 0.12, l - lb) * smoothstep(0.15, 0.25, t.r - t.b) * step(t.b, t.g);
  return vec4(b.rgb, max(white, yellow * 2.0) * (yellow > white ? -1.0 : 1.0));
}
// the photographed city materials (p_citymat.js): layer, uv in repeats of the photo
uniform highp sampler2DArray uMat;
uniform float uMatOn;
vec3 matC(float layer, vec2 uv){ return texture(uMat, vec3(uv, layer)).rgb; }
vec3 matAvg(float layer){ return textureLod(uMat, vec3(0.5, 0.5, layer), 12.0).rgb; }
// ...and their relief and gloss: the normal in the material's own frame (x the way u runs, y the way v runs, z out
// of the surface) and the roughness; flat and middling until the maps have come
uniform highp sampler2DArray uMatN;
uniform float uMatNOn;
vec4 matN(float layer, vec2 uv){
  if (uMatNOn < 0.5) return vec4(0.0, 0.0, 1.0, 0.6);
  vec3 t = texture(uMatN, vec3(uv, layer)).rgb; vec2 xy = t.xy * 2.0 - 1.0;
  return vec4(xy, sqrt(max(1.0 - dot(xy, xy), 0.0)), t.z);
}
// (the same with the uv's screen derivatives given: safe inside a branch that differs from pixel to pixel)
vec4 matNg(float layer, vec2 uv, vec2 gx, vec2 gy){
  if (uMatNOn < 0.5) return vec4(0.0, 0.0, 1.0, 0.6);
  vec3 t = textureGrad(uMatN, vec3(uv, layer), gx, gy).rgb; vec2 xy = t.xy * 2.0 - 1.0;
  return vec4(xy, sqrt(max(1.0 - dot(xy, xy), 0.0)), t.z);
}
// the normal of level ground with a material laid on it by world x, z (uv = xz / size); k: how much relief
vec3 groundN(vec4 nm, float k){ return normalize(vec3(nm.x * k, nm.z, nm.y * k)); }
// a surface's texture frame where it is drawn, from the screen derivatives of its position and uv (p: relative to
// the camera, for precision): the way u and v run on it, and its normal N
mat3 uvFrame(vec3 N, vec3 p, vec2 uv){
  vec3 dp1 = dFdx(p), dp2 = dFdy(p); vec2 duv1 = dFdx(uv), duv2 = dFdy(uv);
  vec3 a = cross(dp2, N), b = cross(N, dp1);
  vec3 T = a * duv1.x + b * duv2.x, B = a * duv1.y + b * duv2.y;
  float im = inversesqrt(max(max(dot(T, T), dot(B, B)), 1e-24));
  return mat3(T * im, B * im, N);
}
// a rough surface's sun highlight (normalised Blinn-Phong for a roughness), times its Fresnel
float specSun(vec3 n, vec3 V, float rough, float f0){
  vec3 H = normalize(V + uSunDir); float a = max(rough * rough, 0.02), ex = 2.0 / (a * a) - 2.0;
  return pow(max(dot(n, H), 0.0), ex) * (ex + 8.0) / 25.0 * fresnelS(max(dot(n, V), 1e-3), f0);
}
// the sun's shadow map round the car (p_sunshadow.js): 1 lit, down to 1 - strength in shadow
uniform highp sampler2DShadow uSunShadow;
uniform mat4 uSunVP;
uniform vec4 uSunSh;     // strength, texel size
float sunShadow(vec3 w, vec3 n){
  if (uSunSh.x <= 0.0) return 1.0;
  vec3 c = (uSunVP * vec4(w + n * 0.12, 1.0)).xyz * 0.5 + 0.5;
  vec2 e = abs(c.xy - 0.5) * 2.0;
  float edge = smoothstep(0.82, 0.98, max(e.x, e.y));
  if (edge >= 1.0 || c.z >= 1.0) return 1.0;
  float s = 0.0, t = uSunSh.y * 1.25;
  for (int i = -1; i <= 1; i++) for (int j = -1; j <= 1; j++) s += texture(uSunShadow, vec3(c.xy + vec2(float(i), float(j)) * t, c.z - 0.00012));
  return 1.0 - (1.0 - s / 9.0) * (1.0 - edge) * uSunSh.x;
}
`;
const TERRAIN_FS = GLSL_HEAD + GLSL_COMMON + GLSL_SHADOW + `

out vec4 outColor;
void main(){

  vec4 nt = texture(uNormalTex, uv);

// ---------- mesh building ----------
class MeshBuilder {
  constructor() { this.pos = []; this.nrm = []; this.col = []; }
  tri(a, b, c, na, nb, nc, ca, cb, cc) {
    this.pos.push(a[0], a[1], a[2], b[0], b[1], b[2], c[0], c[1], c[2]);
    this.nrm.push(na[0], na[1], na[2], nb[0], nb[1], nb[2], nc[0], nc[1], nc[2]);
    this.col.push(ca[0], ca[1], ca[2], cb[0], cb[1], cb[2], cc[0], cc[1], cc[2]);
  }
  // quad a-b-c-d, oriented to face away from `ref`, flat shaded
  quad(a, b, c, d, col, ref) {
    let n = vcross(vsub(c, a), vsub(d, b));
    const fc = vscale(vadd(vadd(a, b), vadd(c, d)), 0.25);
    if (vdot(n, vsub(fc, ref)) < 0) { [b, d] = [d, b]; n = vscale(n, -1); }
    n = vnorm(n);
    this.tri(a, b, c, n, n, n, col, col, col); this.tri(a, c, d, n, n, n, col, col, col);
  }
  box(c, s, col, yaw = 0) {
    const cs = Math.cos(yaw), sn = Math.sin(yaw);
    const P = (x, y, z) => [c[0] + x * cs + z * sn, c[1] + y, c[2] - x * sn + z * cs];
    const hx = s[0] / 2, hy = s[1] / 2, hz = s[2] / 2;
    const v = [P(-hx, -hy, -hz), P(hx, -hy, -hz), P(hx, hy, -hz), P(-hx, hy, -hz), P(-hx, -hy, hz), P(hx, -hy, hz), P(hx, hy, hz), P(-hx, hy, hz)];
    const cc = typeof col[0] === 'number' ? () => col : i => col[i];
    this.quad(v[0], v[1], v[2], v[3], cc(0), c); this.quad(v[4], v[5], v[6], v[7], cc(1), c);
    this.quad(v[0], v[1], v[5], v[4], cc(2), c); this.quad(v[3], v[2], v[6], v[7], cc(3), c);
    this.quad(v[0], v[3], v[7], v[4], cc(4), c); this.quad(v[1], v[2], v[6], v[5], cc(5), c);
  }
  // loft through closed rings (arrays of points, equal length). color: [r,g,b] or fn(point)
  loft(rings, color, opt = {}) {
    const R = rings.length, M = rings[0].length, smooth = opt.smooth !== false;
    const colorOf = typeof color === 'function' ? color : () => color;
    const cent = rings.map(r => vscale(r.reduce((s, p) => vadd(s, p), [0, 0, 0]), 1 / r.length));
    const acc = rings.map(r => r.map(() => [0, 0, 0]));
    const faces = [];
    for (let r = 0; r < R - 1; r++) {
      const axis = vlerp(cent[r], cent[r + 1], 0.5);
      for (let m = 0; m < M; m++) {
        let q = [[r, m], [r, (m + 1) % M], [r + 1, (m + 1) % M], [r + 1, m]];
        const P = q.map(([a, b]) => rings[a][b]);
        let n = vcross(vsub(P[2], P[0]), vsub(P[3], P[1]));
        const fc = vscale(vadd(vadd(P[0], P[1]), vadd(P[2], P[3])), 0.25);
        if (vdot(n, vsub(fc, opt.ref || axis)) < 0) { q = [q[0], q[3], q[2], q[1]]; n = vscale(n, -1); }
        if (vlen(n) < 1e-9) continue;
        n = vnorm(n);
        faces.push([q, n]);
        for (const [a, b] of q) acc[a][b] = vadd(acc[a][b], n);
      }
    }
    for (const [q, n] of faces) {
      const P = q.map(([a, b]) => rings[a][b]);
      const N = q.map(([a, b]) => smooth ? vnorm(acc[a][b]) : n);
      const C = P.map(colorOf);
      this.tri(P[0], P[1], P[2], N[0], N[1], N[2], C[0], C[1], C[2]);
      this.tri(P[0], P[2], P[3], N[0], N[2], N[3], C[0], C[2], C[3]);
    }
    const cap = (r, other) => {
      const c = cent[r], out = vnorm(vsub(c, cent[other]));
      for (let m = 0; m < M; m++) {
        let a = rings[r][m], b = rings[r][(m + 1) % M];
        let n = vcross(vsub(a, c), vsub(b, c));
        if (vdot(n, out) < 0) { [a, b] = [b, a]; }
        const cc = colorOf(c);
        this.tri(c, a, b, out, out, out, cc, colorOf(a), colorOf(b));
      }
    };
    if (opt.capStart) cap(0, 1);
    if (opt.capEnd) cap(R - 1, R - 2);
  }
  cylinder(p0, p1, r0, r1, seg, col, caps = true) {
    const ax = vnorm(vsub(p1, p0));
    const helper = Math.abs(ax[1]) < 0.9 ? [0, 1, 0] : [1, 0, 0];
    const u = vnorm(vcross(ax, helper)), v = vcross(ax, u);
    const ring = (p, r) => Array.from({ length: seg }, (_, i) => {
      const a = i / seg * Math.PI * 2; return vadd(p, vadd(vscale(u, Math.cos(a) * r), vscale(v, Math.sin(a) * r)));
    });
    this.loft([ring(p0, r0), ring(p1, r1)], col, { capStart: caps, capEnd: caps, smooth: seg > 6 });
  }
  build() {
    return { pos: new Float32Array(this.pos), nrm: new Float32Array(this.nrm), col: new Float32Array(this.col), count: this.pos.length / 3 };
  }
}
function uploadMesh(m, instanceData) {
  const attrs = [{ loc: 0, size: 3, data: m.pos }, { loc: 1, size: 3, data: m.nrm }, { loc: 2, size: 3, data: m.col }];
  if (instanceData) attrs.push({ data: instanceData, stride: 8, layout: [[4, 3, 0], [5, 2, 3], [6, 3, 5]], divisor: 1, dynamic: true });
  const v = makeVAO(attrs);
  v.count = m.count;
  return v;
}

const TINT = [-1, -1, -1];
function makeConiferMesh() {
  const b = new MeshBuilder();
  b.cylinder([0, 0, 0], [0, 0.2, 0], 0.045, 0.035, 5, [0.30, 0.22, 0.14], false);
  const cone = (y0, y1, r) => {
    const ring = Array.from({ length: 7 }, (_, i) => { const a = i / 7 * Math.PI * 2; return [Math.cos(a) * r, y0, Math.sin(a) * r]; });
    const tip = Array.from({ length: 7 }, () => [0, y1, 0]);
    b.loft([ring, tip], TINT, { capStart: true, smooth: false });
  };
  cone(0.12, 0.62, 0.30); cone(0.36, 0.84, 0.24); cone(0.60, 1.0, 0.16);
  return b.build();
}
function makeBroadleafMesh() {
  const b = new MeshBuilder();
  b.cylinder([0, 0, 0], [0, 0.42, 0], 0.05, 0.035, 5, [0.33, 0.24, 0.15], false);
  const rings = [];
  const lat = 6, lon = 8, rng = makeRng(5);
  for (let i = 0; i <= lat; i++) {
    const t = i / lat * Math.PI, rr = Math.sin(t) * 0.36, y = 0.62 - Math.cos(t) * 0.32;
    rings.push(Array.from({ length: lon }, (_, k) => {
      const a = k / lon * Math.PI * 2, j = i > 0 && i < lat ? 0.85 + rng() * 0.3 : 1;
      return [Math.cos(a) * rr * j, y, Math.sin(a) * rr * j];
    }));
  }
  b.loft(rings, TINT, { smooth: false, ref: [0, 0.62, 0] });
  return b.build();
}
function makeHouseMesh() {
  const b = new MeshBuilder();
  const wall = [0.90, 0.87, 0.80];
  b.box([0, 0.28, 0], [1, 0.56, 0.72], wall);
  // gable roof along x
  const y0 = 0.56, y1 = 0.88, hw = 0.56, hd = 0.44;
  const A = [-hw, y0, -hd], B = [hw, y0, -hd], C = [hw, y1, 0], D = [-hw, y1, 0], E = [-hw, y0, hd], F = [hw, y0, hd];
  const ref = [0, 0.5, 0];
  b.quad(A, B, C, D, TINT, ref); b.quad(E, F, C, D, TINT, ref);
  b.quad([-0.5, y0, -0.36], [-0.5, y0, 0.36], [-0.5, 0.84, 0], [-0.5, 0.84, 0], wall, ref);
  b.quad([0.5, y0, -0.36], [0.5, y0, 0.36], [0.5, 0.84, 0], [0.5, 0.84, 0], wall, ref);
  return b.build();
}

function initProps() {
  if (!props.conifer) {
    props.conifer = uploadMesh(makeConiferMesh(), new Float32Array(8));
    props.broad = uploadMesh(makeBroadleafMesh(), new Float32Array(8));
    props.house = uploadMesh(makeHouseMesh(), new Float32Array(8));
    props.tower = uploadMesh(makeTowerMesh(), new Float32Array(8));
  }
  props.nConifer = props.nBroad = 0; props.center = [1e9, 0, 1e9];
  const rng = makeRng(4242), houses = [], towers = [];
  const roofs = [[0.62, 0.20, 0.15], [0.35, 0.38, 0.45], [0.20, 0.30, 0.48], [0.50, 0.30, 0.22], [0.42, 0.42, 0.40]];
  const inAirport = (x, z) => {
    const [u, v0] = worldToRwy(x, z), v = v0 * (RWY.side || 1);
    return Math.abs(u) < RWY.len / 2 + 250 && v > -240 && v < 120;
  };
  const grid = new Map();
  const free = (x, z, r) => {
    const gx = Math.floor(x / 30), gz = Math.floor(z / 30);
    for (let a = -1; a <= 1; a++) for (let b = -1; b <= 1; b++) for (const o of grid.get((gx + a) + ',' + (gz + b)) || []) if (Math.hypot(o[0] - x, o[1] - z) < r) return false;
    return true;
  };
  const add = (list, x, z, h, sc, yaw, col) => {
    list.push([x, h - 0.3, z, sc, yaw, col[0], col[1], col[2]]);
    const key = Math.floor(x / 30) + ',' + Math.floor(z / 30);
    if (!grid.has(key)) grid.set(key, []); grid.get(key).push([x, z]);
  };
  const tryHouse = (x, z, maxH) => {
    if (Math.abs(x) > HM_HALF - 200 || Math.abs(z) > HM_HALF - 200) return false;
    const h = terrainHeight(x, z);
    if (h < 2 || h > maxH || terrainNormal(x, z)[1] < 0.965 || onPaved(x, z) || inAirport(x, z) || !free(x, z, 20)) return false;
    add(houses, x, z, h, 9 + rng() * 5, Math.round(rng() * 4) * Math.PI / 2 + (rng() - 0.5) * 0.3, roofs[Math.floor(rng() * roofs.length)]);
    return true;
  };
  if (MAP.procedural) {
    const centres = [rwyToWorld(250, 520), rwyToWorld(-450, 700), rwyToWorld(900, 380)];
    for (let t = 0; t < 4000 && houses.length < 180; t++) {
      const c = centres[t % 3], a = rng() * Math.PI * 2, r = Math.sqrt(rng()) * 520;
      tryHouse(c[0] + Math.cos(a) * r, c[2] + Math.sin(a) * r, 120);
    }
  } else if (URBAN[MAP.id]) {
    // city: dense low houses on the flat lowland, taller buildings where it is lowest and flattest
    for (let t = 0; t < 60000 && houses.length < 3600; t++) {
      const x = (rng() * 2 - 1) * HM_HALF, z = (rng() * 2 - 1) * HM_HALF, h = terrainHeight(x, z);
      if (h > 2 && rng() < 1 - h / 90) tryHouse(x, z, 90);
    }
    for (let t = 0; t < 30000 && towers.length < 450; t++) {
      const x = (rng() * 2 - 1) * HM_HALF, z = (rng() * 2 - 1) * HM_HALF, h = terrainHeight(x, z);
      if (h < 2 || h > 25 || Math.abs(x) > HM_HALF - 300 || Math.abs(z) > HM_HALF - 300) continue;
      if (terrainNormal(x, z)[1] < 0.99 || onPaved(x, z) || inAirport(x, z) || !free(x, z, 45)) continue;
      const g = 0.55 + rng() * 0.35;
      add(towers, x, z, h, 40 + rng() * rng() * 110, rng() * Math.PI, [g, g * 1.01, g * 1.04]);
    }
  } else {
    // islands: villages on the low, flat land near the coast
    const villages = [];
    for (let t = 0; t < 5000 && villages.length < 26; t++) {
      const x = (rng() * 2 - 1) * HM_HALF, z = (rng() * 2 - 1) * HM_HALF, h = terrainHeight(x, z);
      if (h > 3 && h < 90 && terrainNormal(x, z)[1] > 0.97 && !inAirport(x, z)) villages.push([x, z, 20 + Math.floor(rng() * 50)]);
    }
    for (const [vx, vz, n] of villages) {
      let placed = 0;
      for (let t = 0; t < n * 12 && placed < n; t++) {
        const a = rng() * Math.PI * 2, r = Math.sqrt(rng()) * (180 + n * 5);
        if (tryHouse(vx + Math.cos(a) * r, vz + Math.sin(a) * r, 160)) placed++;
      }
    }
  }
  gl.bindBuffer(gl.ARRAY_BUFFER, props.house.bufs[3]);
  gl.bufferData(gl.ARRAY_BUFFER, new Float32Array(houses.flat()), gl.STATIC_DRAW);
  gl.bindBuffer(gl.ARRAY_BUFFER, props.tower.bufs[3]);
  gl.bufferData(gl.ARRAY_BUFFER, new Float32Array(towers.flat()), gl.STATIC_DRAW);
  props.nHouse = houses.length; props.nTower = towers.length;
}
function updateTrees(cam) {
  if (Math.hypot(cam[0] - props.center[0], cam[2] - props.center[2]) < 250) return;
  props.center = [cam[0], 0, cam[2]];
  const cell = 24, gx0 = Math.floor((cam[0] - props.treeR) / cell), gx1 = Math.ceil((cam[0] + props.treeR) / cell);
  const gz0 = Math.floor((cam[2] - props.treeR) / cell), gz1 = Math.ceil((cam[2] + props.treeR) / cell);
  const con = [], brd = [];
  for (let gz = gz0; gz <= gz1; gz++) for (let gx = gx0; gx <= gx1; gx++) {
    const r0 = hash2(gx, gz, 1);
    const x = (gx + hash2(gx, gz, 2)) * cell, z = (gz + hash2(gx, gz, 3)) * cell;
    if (Math.abs(x) > HM_HALF || Math.abs(z) > HM_HALF) continue;
    if ((x - cam[0]) ** 2 + (z - cam[2]) ** 2 > props.treeR * props.treeR) continue;
    const veg = vegAt(x, z);
    const p = smoothstep(0.48, 0.70, veg) * 0.95 + 0.03;
    if (r0 > p) continue;
    const h = terrainHeight(x, z);
    if (h < 4 || h > 980) continue;
    const n = terrainNormal(x, z);
    if (n[1] < 0.84) continue;
    if (onPaved(x, z)) continue;
    const s = 9 + hash2(gx, gz, 4) * 9, yaw = hash2(gx, gz, 5) * 6.28, t = hash2(gx, gz, 6);
    const conifer = h > 260 + t * 200 || (veg > 0.62 && t < 0.35);
    if (conifer) con.push(x, h - 0.4, z, s * 1.15, yaw, 0.13 + t * 0.06, 0.25 + t * 0.07, 0.13 + t * 0.03);
    else brd.push(x, h - 0.4, z, s, yaw, 0.20 + t * 0.12, 0.34 + t * 0.12, 0.12 + t * 0.05);
  }
  gl.bindBuffer(gl.ARRAY_BUFFER, props.conifer.bufs[3]);
  gl.bufferData(gl.ARRAY_BUFFER, new Float32Array(con), gl.DYNAMIC_DRAW);
  gl.bindBuffer(gl.ARRAY_BUFFER, props.broad.bufs[3]);
  gl.bufferData(gl.ARRAY_BUFFER, new Float32Array(brd), gl.DYNAMIC_DRAW);
  props.nConifer = con.length / 8; props.nBroad = brd.length / 8;
}

// ---------- ring course: a loop around the land, following the terrain ----------
const course = { rings: [], radius: 30 };
function buildRingCourse() {
  const rng = makeRng(31);
  let sx = 0, sz = 0, cnt = 0;
  for (let j = 0; j < HM_N; j += 4) for (let i = 0; i < HM_N; i += 4) {
    if (heights[j * HM_N + i] > 5) { sx += -HM_HALF + i * HM_CELL; sz += -HM_HALF + j * HM_CELL; cnt++; }
  }
  const cx = cnt ? sx / cnt : 0, cz = cnt ? sz / cnt : 0;
  const landR = Math.sqrt(cnt * (4 * HM_CELL) ** 2 / Math.PI);
  course.centre = [cx, 0, cz]; course.landR = landR;
  const R0 = clamp(landR * 0.62, 1800, 5500), lim = HM_HALF - 1500;
  const pts = [], n = 10;
  for (let i = 0; i < n; i++) {
    const a = Math.PI * 0.55 - i / n * Math.PI * 2 * 0.92;
    const r = R0 * (1 + Math.sin(i * 2.1) * 0.25) + rng() * 300;
    pts.push([clamp(cx + Math.cos(a) * r, -lim, lim), 0, clamp(cz + Math.sin(a) * r, -lim, lim)]);
  }
  for (const p of pts) {
    let top = terrainHeight(p[0], p[2]);
    for (let k = 0; k < 12; k++) { const a = k / 12 * Math.PI * 2; top = Math.max(top, terrainHeight(p[0] + Math.cos(a) * 160, p[2] + Math.sin(a) * 160)); }
    p[1] = Math.max(Math.max(top, 0) + 90 + rng() * 60, 160);
  }
  for (let pass = 0; pass < 6; pass++) for (let i = 0; i < n - 1; i++) {
    const a = pts[i], b = pts[i + 1];
    for (let t = 0.05; t < 1; t += 0.05) {
      const x = lerp(a[0], b[0], t), z = lerp(a[2], b[2], t), y = lerp(a[1], b[1], t);
      const need = Math.max(terrainHeight(x, z), 0) + 100;
      if (y < need) { a[1] += (need - y) * 0.6; b[1] += (need - y) * 0.6; }
    }
    const d = Math.hypot(b[0] - a[0], b[2] - a[2]), maxDy = d * 0.14;
    if (b[1] - a[1] > maxDy) a[1] = b[1] - maxDy;
    if (a[1] - b[1] > maxDy) b[1] = a[1] - maxDy;
  }
  course.rings = pts.map((p, i) => {
    const prev = pts[Math.max(0, i - 1)], next = pts[Math.min(n - 1, i + 1)];
    const dir = i === 0 ? vnorm(vsub(next, p)) : i === n - 1 ? vnorm(vsub(p, prev)) : vnorm(vsub(next, prev));
    return { p, n: vnorm([dir[0], dir[1] * 0.5, dir[2]]) };
  });
  ensureRingMesh();
}
function ensureRingMesh() {
  if (!course.mesh) {
    const b = new MeshBuilder();
    const R = 1, r = 0.065, seg = 48, sides = 8, rings = [];
    for (let i = 0; i <= seg; i++) {
      const a = i / seg * Math.PI * 2, c = [Math.cos(a) * R, Math.sin(a) * R, 0];
      rings.push(Array.from({ length: sides }, (_, k) => {
        const t = k / sides * Math.PI * 2;
        return [c[0] + Math.cos(a) * Math.cos(t) * r, c[1] + Math.sin(a) * Math.cos(t) * r, Math.sin(t) * r];
      }));
    }
    for (let i = 0; i < seg; i++) b.loft([rings[i], rings[i + 1]], [1, 1, 1], { smooth: true });

// ---------- minimap image ----------
function makeMinimap() {
  const S = 256, c = document.createElement('canvas');
  c.width = c.height = S;
  const g = c.getContext('2d'), img = g.createImageData(S, S);
  const sun = vnorm([0.5, 0.7, 0.4]);
  for (let y = 0; y < S; y++) for (let x = 0; x < S; x++) {
    const wx = -HM_HALF + (x + 0.5) / S * HM_HALF * 2, wz = -HM_HALF + (y + 0.5) / S * HM_HALF * 2;
    const h = terrainHeight(wx, wz);
    let col;
    if (h < 0) {
      const t = smoothstep(0, 60, -h);
      col = [lerp(40, 14, t), lerp(120, 50, t), lerp(140, 96, t)];
    } else {
      const n = terrainNormal(wx, wz), sh = clamp(vdot(n, sun) * 1.25, 0.35, 1.15);
      const v = vegAt(wx, wz);
      let base = h < 5 ? [196, 186, 140] : v > 0.58 ? [52, 88, 46] : [104, 128, 64];
      if (h > 700) base = [132, 124, 112];
      if (h > (({ yakushima: 1850, rishiri: 1350 })[MAP.id] || 1150)) base = [226, 230, 236];
      col = base.map(k => k * sh);
    }
    const k = (y * S + x) * 4;
    img.data[k] = col[0]; img.data[k + 1] = col[1]; img.data[k + 2] = col[2]; img.data[k + 3] = 255;
  }
  g.putImageData(img, 0, 0);
  return c;
}

const FLAP_DEG = [0, 10, 20, 30];
// the name of a flap position as that aircraft's lever is marked (Airbus CONF, Boeing detents)
const flapName = (i, A = ACFT) => A.flapLabels ? A.flapLabels[i] : FLAP_DEG[i] + '°';
// the lever positions that exist (some aircraft have 3 detents: UP / half / full)
const flapStops = (A = ACFT) => A.flapStops || [0, 1, 2, 3];
function flapStep(i, dir, A = ACFT) {
  const st = flapStops(A), k = st.indexOf(i) >= 0 ? st.indexOf(i) : st.findIndex(v => v >= i);
  return dir > 0 ? st[(k + 1) % st.length] : st[Math.max(0, k - 1)];
}
