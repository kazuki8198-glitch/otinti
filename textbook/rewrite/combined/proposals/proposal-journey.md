## 0. 要旨

**結論**：今の教科書の 6 部は、公開されている訓練の流れ（ロンドンの英語の座学 → Sanford の Archer → 航法 → 計器 → Seminole → CRM・ジェット）と同じ並びで、課程表の段階（`s0`〜`s5`＝`p1`〜`p6`）とも一致しています。つまり教科書はもう「道のりの本」です。合本はこれを背骨にして、前に **段階 0「出発の前に（日本で、日本語で準備する）」**、後ろに **段階 7「日本の空へ（JCAB 学科と帰国）」** を足し、**8 部（段階 0〜7）・47 章・264 節の 1 冊**にします。基礎教材の中身は、書き直して「その内容が最初に要る段階」に配ります。

**3 つの決まり**
1. **住所はその内容が最初に要る段階に 1 つだけ**。後の段階では 3 行以内のふり返りとリンク（`bk.see`）で呼び戻します。
2. **各段階は「扉 → 本文 → 関門」で閉じる**。扉には課目（37 課目）と、先に読む節・思い出す節を並べます。関門の章には、前の段階をまぜた問い（間隔をあけた復習）と、「日本の空ではここが違う」の表を置きます。関門は CADET の筆記試験（`written1`・`presolo`・`nav`・`instr`・`multi`・`final`）と同じ区切りにします。
3. **日本の決まりは 3 回会う**。米国の決まりを学ぶその場で「日本では」の囲み、段階の関門でまとめの表、段階 7 で数字と図をそろえた本文、の 3 回です。JCAB の学科は受ける時期が公表されていないので、どの段階からも開ける「JCAB 学科の道（科目別の地図）」で結びます。

## 1. この角度の主張と、証拠を見て直したところ

### 1.1 主張：なぜ「道のり」を背骨にするか

1. **教科書と課程とゲームは、もう段階で組まれている**。教科書の部 `p1`〜`p6` は課程表の段階の `phase` と同じで（`syllabus.js` の `STAGES`、テストで確認）、課目 37 のうち 35 が節にリンクしています。CADET の 1 日の流れ（授業 → 学科試験 → ソロ前 → 航法 → 計器 → 双発 → 最終）も同じ区切りです。合本を主題の順に組み直すと、この背骨を切ることになります。
2. **ゲームはもう「間隔をあけた交互の復習」をしている**。CADET の筆記試験は、前の分野をくり返し混ぜます：規則（`q_law`）は `written1`・`presolo`・`final`、気象（`q_wx`）は `written1`・`nav`、人間（`q_hf`）は `written1`・`instr`、緊急（`q_emg`）は `presolo`・`multi`、操縦（`q_ops`）は `presolo`・`final`（`career.js` の `EXAMS`）。本もこの区切りで関門を置けば、読む・答える・飛ぶが同じ周期で回ります。
3. **2 冊の弱点は「つながっていない」こと**。報告はどの主題でも「教科書＝何をどうするか、基礎教材＝なぜ・いつやめるか」で、片方だけでは足りないと書きます（systems.md は最大の穴を「両方にあるのに、つながっていない」と書く）。基礎教材は主題の順なので、「今日の課目の前に、どの説明を読めばよいか」が分かりません。道のりで組むと、基礎教材の「なぜ」が、それを使う課目のすぐ前に来ます。
4. **日米の取り違えは「その場で並べる」ほど防げる**。curriculum.md 7.3 は「日本の内容を最後にまとめるだけだと、Sanford で覚えた米国の数値を日本の数値と取り違えやすい」と書きます。道のり型は、米国の数字を初めて覚える節で日本の数字を並べ、段階の関門でもう一度、帰国の段階でもう一度と、間隔をあけて 3 回会わせます。
5. **訓練生には「試験・場面」が 3 つある**（curriculum.md 7.1：ロンドンの座学、Sanford の米国の空、JCAB の学科と帰国後）。1 冊の中で「今どの場面か」を部の扉で示せば、読む人は迷いません。
6. **読む人は「これを今なぜ読むのか」が分かる**。各節の頭に「この節を使う場面」（課目・関門・FAA と JCAB の試験の科目）を札で出します。基礎教材の読者が疲れる理由（留保が 1 章 40〜75 回、「何をすればよいか」が見えない：wb-perf.md・weather.md）の多くは、目的が見えないことです。

## 2. 設計の決まり（12 条）

1. **置き場所の決まり**：その内容を使う最初の場面（課目・関門・試験・訓練の段階）がある段階に置く。座学で学ぶのが事実のもの（1.2 A）は段階 1。迷ったら早い方。
2. **1 概念 1 住所**：完全な説明は 1 か所。ほかの場所は「思い出そう」の 3 行以内と `bk.see`。
3. **節 ID・章 ID は変えない**。新しい中身は新しい ID。節を別の章へ移すのは 4 節だけ（`sys.g1000`・`sys.compass` → `inst`、`perf.wb`・`perf.wbex` → `wb`）。章 `intro`・`sim` は部 `p0` へ移す（ID はそのまま）。
4. **部（段階）の形**：扉（`PARTS` の新しい項目 `intro`：目標・課目の表・思い出す節）→ 章 → 関門の章（`g1`〜`g7`：`gN.review` と `gN.japan`。段階 7 は `g7.review` と `g7.oral`）。
5. **節の形は教科書のまま**（CADET が読む）：ねらい（`bk.aim`）→ 使う場面の札（メタデータから表示）→ 最初の図 → 説明 → もっと深く（`bk.deep`）→ 判断の目（`bk.judge`）→ ここを混同しない（`bk.dont`）→ ここが大切（`bk.key` 2〜4 項目）→ よくある間違い → 米国では／日本では（`bk.us`／`bk.jp`）→ 考えてみよう → 写真 → シミュレータで体験（最後）。
6. **範囲の印**：節のデータに `scope: 'common'|'us'|'jp'|'mixed'`。規則の数字は必ず「どこの規則か」と一緒に置く（文字の検査）。
7. **段階 1〜6 の本文は「共通＋米国」、段階 7 の本文は「日本」**。段階 0 は両方の地図。
8. **基礎教材の文は書き直す**。転記しない。節ごとに由来 `from: ['kiso05.14', …]` を持ち、画面に「パイロット基礎教材 第 3 版 第 5 章 14 節をもとに改稿」と出す。`flight-lab/kiso/` は一字も変えない。
9. **図**：暗い板（#0b1422）・幅 360〜440・文字 12 以上・単独で正しい XML・`aria-label`。基礎教材から取る図は描き直す（元の図番号を記録）。
10. **写真**：クレジットは写真の下。CC BY-SA の写真は新しい切り抜き・色調整・文字入れをしない（基礎教材の写真はファイルをそのまま使う）。航空会社の写真は使わない（基礎教材第 0 章の扉の全日空の写真は外す）。一覧は `PHOTO-CREDITS.md` に 1 つ。加工の表示は写真ごとのデータで出す（今は `bk.photo` が一律に「縮小などの加工あり」と書く）。
11. **章末の確認問題は後ろに足すだけ**（学習記録 `bookQuiz` のキーが「章ID.番号」）。誤りは文の中で直す。学科テストの分野 ID 14 は変えず、新しい分野は足す。
12. **事実は出典つき**：「教材値」「参考値（出典・節）」「条文（e-Gov、確認日）」のどれか。確かめられない日本の項目は「推測・要確認」の札か、書かない。

## 11. 「完璧」の基準と確かめ方

「完璧」を、次の 20 の検査がすべて通ることと決めます（自動の検査は新しいテストとして足し、人の確認は台帳に記録する）。

**A. 正しさ**
1. **既知の誤りの台帳**（12 の報告の教科書・基礎教材の誤り 約 120 件）がすべて閉じている。各件に直した場所・根拠・確かめた人。特定の文はテストで確かめる（例：`q_perf` に「98」、`perf.fuel` に「最初の着陸予定地」）。
2. **主張の台帳**：書き直した・新しい文のうち、数字・条文・手順を含む文を自動で抜き出し（数字＋単位、条番号、14 CFR・AIM・航空法の正規表現）、すべてに出典の札がある。確認は書いた人と別の確認役の 2 人。日本の法令は e-Gov の本文で確認日つき。確かめられないものは「推測・要確認」。
3. **計算の再計算**：数値例を JSON にして、式で再計算して一致（基礎教材から移した計算・Archer と Seminole の例・換算の表）。

**B. 管轄**
4. 「14 CFR／91.xxx／AIM」は `scope` が `us` か `bk.us` の中、「航空法／施行規則／第 n 条」は `jp` か `bk.jp` の中（文字の検査）。
5. 取り違えの表（付録 A）の約 40 項目が、その段階の囲みと段階 7 の住所の両方にある（テスト）。

**C. 道のり**
6. 37 課目の `book` の節は、その課目の段階と同じか前の部にある（テスト）。
7. 後ろの部への `bk.see` は「予告」の印つきだけで、全体で 40 本以下（テスト）。
8. 各部の扉に前の段階への呼び戻しが 6 本以上、うち 2 段階以上前が 2 本以上（テスト）。
9. 各関門の問いの 30% 以上が前の段階の内容（メタデータで確かめる）。
10. 1 概念 1 住所：重複の台帳（詰まりの表・コンパスの誤差・高度計の誤差・風の三角形・受け渡し 3 段階・TEM の言葉・VFR と IFR の区別など 20 件）で、本体は 1 か所、ほかは 3 行以内（文字数の検査）。

**D. わかりやすさ**
11. STYLE.md：1 文の平均 40 字以下・最長 80 字、です・ます、初出の用語は「日本語（English）」、留保の言い方（とは限りません等）は 1 節 1 回まで（文字の検査）。

**E. 図と写真**

## 14. リスクと対策

| # | リスク | 対策 |
|---|---|---|
| 1 | 段階に置く場所でもめる（座学で先に学ぶか、使う段階か） | 置き場所の決まり（2 章 1 条）と「迷ったら早い方」。1 概念 1 住所なので、置き場所を後で変えても ID とリンクは壊れない |

| 3 | CADET の台詞の質が下がる（基礎教材の形は `bk.aim`・`bk.key` を持たない） | 新しい節もすべて教科書の節の形で書く（検査 12）。段階 0・7 と関門は CADET に出さない |
| 4 | 管轄が混ざって、課目（米国の ACS）や学科テスト（米国の数字）と食い違う | `scope` と囲み、文字の検査（検査 4）。段階 1〜6 の本文は米国、日本は囲みと段階 7 |

## 15. 利用者に決めてもらうこと

1. 1 冊・8 段階の構成でよいか。本とアプリの入口の名前（「教科書」のままか、「訓練の道のり」などにするか）。
2. 課程表の段階の題を「第 1〜6 段階」に直し、本の部の番号とそろえてよいか（ID と `phase` は変えない）。
3. 段階 7 の深さ：JCAB の事業用＋計器飛行一般の学科の水準まで書くか、自家用の水準で止めるか（工数が約 80 時間変わる）。
4. 用語の切り替え（段階 0〜6 は教科書の言い方、段階 7 は JCAB の言い方）でよいか。
5. 復習の仕組み（記録に `readAt`・`review` を足す）を入れるか。
6. 基礎教材（第 3 版・原本）のアプリの入口を、移し終えたあと外すか（リポジトリと `preview.html` には残す）。CADET の授業に新しい章（`inst`・`wb`・`navb`）を足すか。
