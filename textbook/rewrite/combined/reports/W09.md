## 2. したことと理由

### 2.1 `FL.book.addPart`（DESIGN 3.1）

`book-core.js` の固定の `PARTS` に p0 を書き足さず、部を足す関数を作りました。部は、その部の章を持つファイルが足します（p0 は `book-0.js`、R4 で p7 は `book-7.js`）。CADET は `book-7.js` を読まないので、CADET の `PARTS` に p7 は入りません。

- 形：`{ id: /^p[0-9]+$/, title, door（任意）, before（その前に入れる部の id。なければ最後）}`。`PARTS` は読む順番の列で、目次（FLIGHT LAB の `pages.js`・TEXTBOOK の `render.js`）はこの順に部を出します。章の番号は `CHAPTERS` の中の位置です（`add` のまま）。
- 同じ id の部・ない `before`・id や題のない部は、例外にしました（打ち間違いを隠さない。`bk.jur` の id と同じ考え方）。例外のときは `PARTS` を変えません（テストで確かめた）。
- `door`（部の扉）はまだ描く所がありません（W10・W25・W35）。`phase` は第 1〜6 部だけが持ちます（課程表の段階の `phase` は p1〜p6 のまま。3.1）。

### 2.2 直書きの「第 N 章」（決まり 2・3）

番号を振り直す前に、出典の前置きのない「第 N 章」を全部替えました。検査 `check-chapter-refs.mjs` は 8 → **0**。

| `intro` の章末の用語 `Check flight / Stage check` の補足 | 「第 17 章」 | 「第 2 部のソロの章」（章末の用語の補足は、FLIGHT LAB の `pages.js` も TEXTBOOK の `render.js` も `fix` を通さずに文字のまま出すので、`{ch:solo}` と書くと「{ch:solo}」と出る。部の番号は第 1〜6 部では変わらない） |
