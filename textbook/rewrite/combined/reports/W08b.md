## 2. したこと・理由

DESIGN 3.4 の表で「囲みの節」がこの 2 ファイルにある 15 節・22 項目に、`FL.jur`（`flight-lab/src/book-jur.js`）から描く囲みを置きました。

- **数字は手で書かない**：どの囲みも `bk.jur(...ids)`・`bk.same(id)` に `FL.jur` の項目 ID を渡すだけです。描く文・出典・条文・e-Gov の版は全部データから出ます（DESIGN 3.4「3 回会わせる」、STYLE「囲みの数字は手で書きません」）。事実の確かめは W06（米国：eCFR・AIM・ACS）と W05（日本：e-Gov の写し）が済ませた値で、この単位は新しい数字を書いていません。`bk.same` を使った 1 か所だけは、「同じ」と言ってよいかを e-Gov の写しで自分で確かめました（下の表の注）。
- **手で書くリンクなし**（決まり 6・13）：`{ch:}`・`bk.see` は 1 つも足していません。「第 7 部で詳しく」のリンクは、行き先の節が本に入ったときに部品が自動で出します（R1 では出ません。全 10 章の `FL.book.jurTable` にも `data-sec` なし）。
- **置き場所**：節の形（STYLE「節の形」の 10、`check-form.mjs` の順位 6）に合わせ、「ここが大切」と「ここに注意」のうち後ろにあるものの直後、「考えてみよう」・「シミュレータで体験」の前に置きました。`check-form` の順の warning は前後で同じ（order 29・sim-not-last 23。どれも前からのもの）。
- **部品の選び方**：米国の数字を本文で教えているその場で日本と並べるので、`bk.jur` にしました（DESIGN 3.4「囲み」）。米国の欄は CADET でも「米国の決まり」として残ります（`usSideOnly`。CADET の学科テストが問う米国の規則が、ゲームの中の本にも残る）。日本の欄・e-Gov の版の行だけが CADET から消えます。`fuel.ifr` だけは、DESIGN 3.4 の表が「＝同じ」としているので `bk.same`（日本も同じ）にしました（決まり：違いがないときは `bk.same`）。
- **CADET の決め打ちの文**（決まり 9）：`nav.chart`（架空・NOT FOR NAVIGATION）・`solo.req`（実名の文と消したあとに残る文「訓練回数の決まりはない」）などは変えていません。CADET のテストで確かめました（下の 4）。

## 6. 未解決のこと

1. **`FL.jur` の `cruise` の米国の欄の語**：「磁針路 0〜179°…」と書いているが、14 CFR 91.159(a) は “On a magnetic course of zero degrees through 179 degrees”（eCFR の API で本文を確かめた、2026-10-27）で、**磁航路**（magnetic course）です。`nav.log` の本文と `nav.plan` は「磁航路で決める」と書き、`FL.terms` の「磁針路」は magnetic heading（`magnetic-heading`）なので、囲みが本文のすぐ下で別の語を出しています。`book-jur.js` はこの単位の持ち物でないので直していません（下の 7 の 1）。
2. **`nordo.ifr` の語**：囲み（`FL.jur`）は「割り当て → レーダー誘導の行き先 → 予定と言われた経路」、すぐ上の本文の表（W07b）は「指示された経路 → … → 予告された経路」。意味は同じ（AIM の Assigned・Vectored・Expected）ですが、語がそろっていません。用語の表 `FL.terms` に決まった語がなければ、W24（第 1 部の語）か W30（第 4 部）がそろえる候補です。
3. **検査の道具の数え方**（integrate-P3 の 6 で W01 の持ち主と決めることになっていたもの）：`check-style.mjs` が `bk.same` の値の行（`.jur-v`「題：値」）を文と数え、`ifr.rules` に `long-sentence`（81 字）と `taigen-dome-label` の warning を 1 つずつ出す。表（`bk.jur`）の中の語は `first-use-form` に数える（＋25）。どれも warning で、本文の文ではありません。
4. **`emg.basic` の「危難の場合の日本の決まりは囲み」**（DESIGN 3.3 の目次の欄）：航空法第 74 条・第 75 条（危難の場合の措置）は 47 項目（`FL.jur`）にない項目で、e-Gov の写しにも第 75 条がありません（`textbook/rewrite/sources/egov/articles/kokuho/` に 75 なし）。数字のない日本の決まりなので、写し（W37）ができてから、`bk.jp` に手で書く文にするか `FL.jur` に項目を足すかを決めます。この単位では置いていません（確かめていない条を書かない）。
5. **置き残し**：上の 3 の 13 か所（節がまだない）。
